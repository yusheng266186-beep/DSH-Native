本候选完成阶段五 C，重点升级模型配置、服务商检测、项目级默认模型与首次使用闭环。

## 新增

- 模型中心：服务商、模型和思考强度集中选择，模型列表支持搜索。
- Command Code 与 DeepSeek 官方服务商只读连接检测，并核对当前模型是否实时可用。
- 全局默认之外，可为默认工作区和每个命名项目保存独立模型配置。
- 新安装在运行环境就绪后进入可操作的模型向导；中断可恢复，也可明确稍后设置。

## 改进

- 保存模型或密钥不再强制重启并打断正在运行的任务；配置用于新会话。
- 密钥写入增加 YAML 安全引用、长度与控制字符校验。
- 项目模型映射加入现有加密配置备份，并在项目切换前安全应用。
- DeepSeek 官方路由不再被误报为“不在 Command Code 模型清单”。

## 安全与兼容

- 服务商检测只读取 `/models`，不发送提示词，不调用生成接口。
- 不记录密钥、认证请求头或服务商响应正文。
- 不新增 JavascriptInterface，不调用 DSH 私有 RPC。
- 包名、签名、数据目录、payload、minSdk 24 与 targetSdk 28 不变，可同签名覆盖安装。

完整真机步骤与边界见 `docs/PHASE5C-MODEL-ONBOARDING.md`。
