- 修复 session.v4.jsonl.zstd 首次保存的 link EACCES：新建与迁移均支持排他复制降级并同步文件，保留拒绝覆盖历史及真实磁盘错误。

修复随 APK 启动应用到现有 payload-v12，无需清空数据或重新登录。保留包名与签名，可以覆盖安装。
若提示旧内核尚未加载修复，点击状态页的「重试启动」，或从更新与维护中重启 DSH。
回归使用真实运行包和合成平台；Android 真机上的首次运行及账号设置体验仍需安装后确认。

## English

Fix first-session publication on Android when hard links return EACCES, covering both compressed/plain materialization and migration.
Use an exclusive copy and file sync while preserving collision protection and genuine write/disk errors.

**App tools → DeepSeek account** opens DSH’s original account settings, including profile, topped-up/granted balances,
usage, top-up and sign-out. Model center retains a shortcut. Remove the separate simplified native account panel.
Adapt browser authorization without manufacturing a Desktop bridge, preserve cancel/copy/reopen, and prevent automatic
onboarding from obscuring account settings. Keep private account RPC bodies out of diagnostic logs.

The APK repairs the existing payload-v12 at startup without clearing data or account grants. It retains the package/signing key.
If an older running core is detected, use Retry startup or restart DSH from Updates & maintenance. Real-runtime and synthetic-platform regressions
remain separate from phone acceptance and real provider requests.
