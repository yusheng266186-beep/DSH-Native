# DeepSeek Harness Native 0.28.0 测试候选

本候选完成阶段五 B，重点补齐手机端文件整理与会话管理入口。

## 新增

- 文件多选、批量复制与移动，同名目标自动保留两份。
- 可恢复回收站，支持恢复与二次确认后的永久删除。
- PNG、JPEG、WebP、GIF、BMP 原生图片预览与后台采样解码。
- 会话管理入口，可直接聚焦 DSH 官方搜索并查看已归档会话。

## 安全与兼容

- 文件操作继续受规范路径白名单与符号链接边界保护。
- 默认删除改为移到同卷回收站，永久删除仅在回收站内提供。
- 会话管理不调用 DSH 私有 RPC，不新增 JavascriptInterface。
- 包名、签名、数据目录、payload、minSdk 24 与 targetSdk 28 不变，可同签名覆盖安装。

完整真机步骤与边界见 `docs/PHASE5B-FILES-SESSIONS.md`。
