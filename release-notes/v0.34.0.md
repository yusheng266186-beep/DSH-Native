## 内核与兼容

- 固定升级到 2026-10-23 发布的 DSH `0.2.1-rc.3`，使用官方 npm 归档和完整性值，更新全部依赖锁。
- 保留 Android/bionic Node、可加载的 Android PTY、Pillow 图片处理、会话排他发布和既有用户数据。
- 适配新内核网页账号登录流程：等待真实授权地址后打开系统浏览器，保留取消、重试和回调验证；避免预打开空白页导致 Android 授权无法跳转。
- App 设置依赖与新内核的 modules 服务共同保留，会话回收站恢复和模型思考选择器继续使用真实内核接口。

- 修复旧版原生滚动弹窗的底部操作高度分配，长正文和大字体不再先占满按钮区域。
- 修复窄屏进入插件/自动化等面板时侧栏继续占用 280px、挤压正文的问题；通过真实布局状态收起侧栏，保留大屏布局偏好。
- 旧草稿恢复不再改写富文本编辑器，避免与新内核的命令、附件引用和工作区草稿状态冲突。

## 手机适配与验证

- 使用新内核真实前端验证附件取消、长文件名、文件标签关闭、模型菜单、侧栏、设置导航及账号界面。
- 触屏矩阵包含窄屏、横屏、平板、高像素密度和低高度窗口；窄屏继续保留用户已确认的 480 CSS px 基线。
- 小系统字体、大字体、系统 WebView、系统浏览器往返与真实键盘仍需按设备分别确认。用户常用设备为小米 17 Ultra、当前最新 Android，用户明确自行真机调试，本轮不运行真机验证；浏览器模拟不作为该手机真机验收。
- 完整 Android 构建和实际运行包消费检查通过后才发布，保留既有签名以支持覆盖安装。

## English

Pins the official DSH 0.2.1-rc.3 release and dependency lock, retains the verified Android runtime and data protection, and adapts native settings and system-browser authorization to the new core. Touch regression covers the real frontend across phone, landscape, tablet, high-density and short-height windows. Browser checks do not replace Xiaomi 17 Ultra WebView, IME or on-device acceptance.
