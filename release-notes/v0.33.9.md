修复触屏模式下多处图标按钮被拉成长条，以及打开文件后标题旁的叉号落到下一行。

- 移除全局 44px 按钮高度下限，恢复文件标签关闭、图片与文件取消、发送、侧栏和预览工具的组件尺寸。
- 删除猜测 CSS Module 名称的旧规则，保留 480px 窄屏视口和已恢复正常的设置布局。
- 布局诊断在附件、面板与旋转后重新采集，每条记录独立输出，不记录文件名或正文。
- 新增真实运行包的触屏 Chromium 回归，覆盖六组宽度、横屏、中英文和明暗主题，并检查实际取消与关闭操作。

保留包名、签名和 payload-v12，可覆盖安装。浏览器验证与 Android CI 不替代本版在用户设备上的视觉验收。

## English

Fix stretched touch-mode icons and the file-tab close cross appearing below its title.
Restore upstream button dimensions by removing the global 44px minimum height. Preserve the
480px narrow viewport and working settings adaptation. Layout diagnostics now observe later
interactions with bounded, content-free records. Real-payload Chromium tests cover six touch
scenarios, both languages, light/dark themes, and actual remove/close actions.

Uses the existing package, signing key and payload-v12. Device visual acceptance remains separate
from browser tests and Android CI.
