0.31.3 修复上游模型目录写入后 DSH WebUI 仍显示旧列表的问题，并补上可见的模型列表更新入口。

## 模型目录与 WebUI

- DSH 侧栏新增“更新模型列表 / Refresh models”，点击后可回到模型中心读取当前服务商的实时 `/models` 目录。
- 模型中心新增“更新上游模型列表”按钮；成功读取后，保存会把完整目录写入对应 DSH provider catalog。
- 空闲保存会安全重启 DSH runtime，再重新加载 WebUI，使 provider topology、默认模型和模型选择器使用同一份最新配置。
- 运行任务期间不重启服务，避免中断任务和草稿；目录会保留并在任务结束后应用。

## 兼容与安全

- 入口跟随侧栏布局，收起时不覆盖页面；支持页面刷新、SPA 重绘、横竖屏、深浅主题和中英文。
- 不新增高风险 `JavascriptInterface`，不记录 API key 或上游响应正文。
- 包名、正式签名、用户数据目录、payload-v9、minSdk 24 与 targetSdk 28 不变，可从 `0.31.2` 同签名覆盖安装。

## 验证

- 完整纯逻辑、Java 静态检查、WebUI 注入脚本回归与 Android CI 通过后，由 `release.yml` 发布 stable。
