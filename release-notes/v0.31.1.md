0.31.1 是模型中心的兼容性小版本修复，承接阶段五 E 的实时上游目录与导航能力。

## 模型中心修复

- Command Code 与 DeepSeek 官方直连继续从各自上游 `GET /models` 读取实时目录。
- 上游本次返回的模型全部可以直接点击、保存并用于新会话，不再因本地能力目录尚未更新而显示“不兼容”或被禁用。
- 本地目录只补充图片输入、思考等能力提示；缺少提示不会阻止模型使用。
- 保存校验仍要求模型来自本次成功的上游读取，避免把手工输入或过期静态列表当成在线模型。
- 临时断网时继续允许原样保留已有服务商与模型配置。

## 兼容与升级

- 包名、正式签名、用户数据目录、payload-v9、minSdk 24 与 targetSdk 28 不变。
- 可从当前 0.30.0 正式版及同签名阶段候选直接覆盖安装。
- 会话、密钥、项目、任务历史、文件和工作区不受影响。

## 验证

- 纯逻辑与回归测试全部通过，覆盖未知上游模型可见、可选、可保存及离线旧配置保留。
- 完整 Android CI 仍需完成 javac、DEX、aapt2、APK 清单、签名和产物校验后，才更新稳定清单。
