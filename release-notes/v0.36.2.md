- 根据更新后的环境指南，修复 py3clean / py3compile 的解释器行带空格或制表符时漏修的问题；保留参数、正文与可执行状态，缺失 Perl 不伪报修复。
- 自检直接调用真实文件工具，分别验证私有目录与所选工作区的新建、读回、同名保护及按版本更新；原始 hardlink 失败不再被当成工具不可用的充分证据。提供手动诊断 CLI，错误仅输出阶段和错误码。
- 自检使用唯一临时目录，仅清理自身；工作区变更会重新检查，失败不缓存通过。增加常用可选 Python 库的实际 import 清单，保留 Pillow PNG 往返检查。
- 更新环境指南复核，纠正 Python 原生依赖、TypeScript 与 skills 默认目录等推断。保留用户插件、MCP、审批、历史与项目，不自动安装依赖或批量清理目录。

覆盖安装后从更新与维护重启内核。继续使用 payload-v13、原包名和签名。自动回归覆盖托管脚本、真实文件后端和生产自检接线；按约定不做真机验证，由用户安装调试。

Repairs whitespace-prefixed Python shebangs, probes the actual file-tool backend in the private runtime and selected workspace, and reports optional Python imports. Uses unique temporary directories, preserves existing files and user configuration, and refreshes preflight checks when the workspace changes. Keeps the existing runtime, package and signer.
