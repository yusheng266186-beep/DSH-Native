# 0.35.0

> 版本记录：标题版本对应本次发布，原始变更内容保留，不覆盖为新版说明。 已发布 stable：**1.1.0**；源码：**1.1.1**；源码运行包：`payload-v14`；固定 DSH：`0.2.1-rc.3`（上游候选版）。[统一进度与验证边界](../docs/STATUS.md)。

- 修复通知栏读不到任务状态：原生服务通过认证本机 RPC 获取真实会话运行状态，覆盖后台和网页未加载情况；查询失败显示同步中，重复推送不再重置通知。
- 为语音输入插件接入 Android 系统识别，支持麦克风权限、服务检测、端侧优先、系统窗口回退、取消及超时。识别结果只填草稿，草稿变更时保留文字供手动插入；普通浏览器保留原插件。
- 修复 node/npm/npx 命令入口及托管工具的旧解释器路径，统一私有临时目录，增加 pip/Pillow 实际自检；失败不再缓存成通过。
- 修复共享存储新建文件时硬链接被拒绝，保留同名文件、并发保护和真实磁盘错误。
- 复核环境优化指南并补充使用、诊断与依赖说明；不自动改用户审批、MCP、项目约定或清理任务目录。

沿用 payload-v13 / DSH 0.2.1-rc.3 与既有签名。覆盖安装后重启内核即可应用，无需重下运行包或卸载。语音插件需启用，实际语言、离线能力及是否联网取决于手机系统服务；没有服务时会显示明确提示。

真实内核任务状态、文件后端、语音组件合成回归及多尺寸触屏布局已验证；Android 完整构建与签名由发布流水线检查。按用户约定不做真机验证，系统语音与 ROM 后台行为由用户安装调试。

Adds authenticated native task monitoring, Android system dictation in the existing voice plugin, relocatable tool command repairs, a private temporary directory and an exclusive-copy fallback for new files on Android shared storage. Dictation inserts editable draft text and requires a compatible system speech service. Keeps payload-v13, the signing certificate and user data. Device microphone and ROM behavior remain for user testing.
