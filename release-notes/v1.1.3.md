首页动画与进入聊天页的衔接打磨。

- 放大现有品牌鲸鱼，使用 2.4 秒舒缓轻游，配合静态淡光、两道细水波与小气泡；增加品牌标题，循环中不闪烁、不缩放呼吸。
- 内核连接和界面首帧真实就绪后，立即开始 180ms 平滑交接，无需等待完整动画；关闭系统动画时直接进入。
- 状态文案预留三行空间，相同状态不重复播报。短横屏缩小装饰区域，大字体下可滚动查看。
- 退后台暂停绘制并保留姿态；交接期间断连恢复完整遮罩，失败、重试及销毁清理动画状态。

沿用原签名、包名与 payload-v14，可直接覆盖安装。本地完整 JVM、JS 与 Python 测试通过；生产 StartupView 的 28 项生命周期、绘制、交接、断连、重试和后台暂停检查通过，深浅色绘制预览已检查。本轮不做真机或模拟器验收，实际手机观感与系统绘制效果由用户安装反馈；完整 Android CI 与发布状态以本版 Actions 和发布清单为准。
