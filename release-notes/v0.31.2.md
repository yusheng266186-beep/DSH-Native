0.31.2 修复原生模型中心与 DSH WebUI 模型目录不同步的问题。

## 模型目录同步

- Command Code 与 DeepSeek 官方直连仍从各自官方 `GET /models` 读取实时目录。
- 保存时把本次成功返回的完整模型目录写入 DSH 实际 provider catalog；默认模型和 WebUI 模型选择器使用同一份模型 ID。
- 所有上游返回的模型都可直接选择和保存；未知能力按安全的文本基础能力处理，不再显示“不兼容”而阻止使用。
- 动态目录带有升级保留标记，覆盖安装和启动配置合并不会用旧静态预设覆盖刚保存的上游模型。
- 保存后刷新 WebUI 模型选择器；活动任务期间不刷新页面，避免打断任务和输入草稿。

## 兼容与升级

- 包名、正式签名、用户数据目录、payload-v9、minSdk 24 与 targetSdk 28 不变。
- 可从 `0.31.1` 正式版同签名覆盖安装，不需要卸载，不会清理会话、密钥、项目、任务历史、文件或工作区。
- 不新增高风险 JavascriptInterface，不修改任意 Base URL，不把 API key 或上游响应正文写入日志。

## 验证

- `ModelCatalogSyncTest` 覆盖 Command Code/DeepSeek 写入、去重、幂等、升级合并和目录解析。
- 完整 `scripts/run_tests.sh`、Java 静态检查、Android CI、签名、APK 与稳定清单校验由正式发布工作流执行。
