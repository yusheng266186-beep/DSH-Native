- agent 新增实际 android 工具和 dsh-android 命令，接入手机剪贴板读写、通知、文字/文件分享、打开链接/文件/App 和真实保活状态。
- 新增每次系统授权的单张截图，返回私有 PNG 路径；成功、取消、断开和超时都会释放捕获资源，不连续录屏、不重用授权令牌。
- 原生服务使用私有令牌和随机本机端口；窗口动作校验前台，通知被禁用会明确报错，文件仅限定范围的常规产物。分享返回系统选择器已打开，不误报已经送达。
- 启动时加载 App 自有工具适配器并提供使用说明，无需配置 MCP，不覆盖用户 AGENTS.md、审批、凭据或历史。

覆盖安装后从更新与维护重启内核，agent 可直接使用 android；命令行可运行 dsh-android --help。剪贴板/分享/打开时保持 DSH 前台；截图在手机系统提示中选择范围并授权。仍使用原包名、targetSdk、签名和 payload-v13。自动回归与 Android 构建不等于手机验收，按约定由用户安装验证。

Adds an actual Android agent tool and CLI for clipboard text, notifications, share sheets, opening links/files/apps, keepalive status and a single screenshot with fresh Android consent. Uses authenticated loopback RPC, foreground checks and scoped read-only file sharing. Preserves runtime, user configuration and signer. Restart the core after installing.
