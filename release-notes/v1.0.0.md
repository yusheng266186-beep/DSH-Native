# DSH Native 1.0.0

发布前追加修复：模型目录在当前内核应用，不再因拉取目录重启；长模型弹层支持触摸滑动和末项选择。同版内核退出后的再次启动复用已验证环境，升级前核对旧内核任务。保留品牌鲸鱼，细化比例与轻量动效。

<!-- dsh-doc-status:start -->
> 版本记录：标题版本对应本次发布，原始变更内容保留，不覆盖为新版说明。 已发布 stable：**1.1.2**；源码：**1.1.3**；源码运行包：`payload-v14`；固定 DSH：`0.2.1-rc.3`（上游候选版）。[统一进度与验证边界](../docs/STATUS.md)。
<!-- dsh-doc-status:end -->

六项正式版收尾：后台恢复、更新与数据保护、全页面适配、CodeBuddy 对话、性能诊断、维护与发布校验。

- 后台恢复：修复停机等待阻塞状态读取、旧进程输出污染地址和 stdout 关闭误判退出；仅在前台、任务空闲证据新鲜时恢复网页，不自动重发聊天。
- 更新与数据：配置恢复增加持久撤销记录；运行包替换/恢复保存中断标记，启动先处理未完成事务。失败保留恢复依据，避免混合版本继续运行，保护历史、项目和凭据。
- 手机与平板：修复设置模型导入、配置文件按钮及展开行的大字裁切；平板分类完整换行，所有设备控制器仍融入原 DSH 设置结构。复查旧文件、分享、语音、插件、任务与弹层。
- CodeBuddy：保留官方 SDK/CLI，修复 SDK 错误原因丢失，区分渠道、认证、模型权限、额度、限流及上下文失败；完整校验工具批次后才交给 DSH，支持后续显式继续。
- 性能：后台减少无用 WebView 设置推送；复查预热、取消和 10 秒进程回收，限量清理过期编译缓存。新增不含对话/凭据的启动及首内容阶段计时，便于定位手机延迟。
- 维护：冻结内核、SDK、Android 配置与 11 个引导二进制；新增原设置中的隐私/开源入口、排障说明及依赖清单。发布必须校验资产摘要、下载实际字节和可信 payload 清单后才更新 App 通道。

保持原包名与签名，可覆盖安装；不要卸载清数据。引导包之外的运行包仍为 payload-v13，无需因版本号重复下载未变化分片。加载保留主题小鲸鱼动画和真实就绪交接；缓存统计沿用 0.40.2 修正口径，不回写旧会话。

验证范围：JVM/脚本、生产恢复故障注入、固定实际内核、官方 SDK 对本机合成服务、真实 WebUI/工具/保存链及完整 Android CI。模型消费覆盖长历史、图片传输、写/读/回复、取消和下一次发送；不等同付费服务全模型实测。按用户要求不做真机或模拟器测试；小米系统后台、权限、语音引擎和外部应用体验由安装后反馈确认。

兼容边界：ARM64，Android 7.0+（minSdk 24）；targetSdk 28 与私有目录执行架构保持一致。DSH 内核固定 0.2.1-rc.3，仍为上游候选版；本次 1.0.0 指 DSH Native 的正式版本。配置备份不包含完整会话/项目；诊断不包含正文、附件、密钥和私有恢复记录。

详细检查与结果见 docs/RELEASE_1_0.md、docs/STATUS.md。
