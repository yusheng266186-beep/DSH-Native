缩短进入首页前的不必要等待，针对反馈的半分钟到一分钟启动等待重新整理启动顺序。

- 完整工具、Python 与网络能力检查移到首页显示后的前台空闲阶段；可选检查失败不再阻止复用已验证的运行环境，同一失败环境一小时内不反复检查。
- 复用有效组件回执、可信运行包和工具指纹，冷启已准备好的环境时跳过重复安装、重复 Node 版本探针和未变化的配置迁移；首次安装、环境变化、缺件及待更新仍走完整准备。
- 修复工具准备回执在自身修复后失效的问题。聊天、退后台、重启、运行包维护和配置恢复优先，旧检查可取消，不占着环境锁拖住重启。
- 保留真实本机服务、连接和首页绘制判定；启动日志分开记录配置阶段与首页交接后的能力检查耗时。

保持原签名、包名和 payload-v14，直接覆盖安装，项目、历史、附件和账号配置保留。已完整安装运行包的用户无需重新下载运行包。本版仍不做真机或模拟器测试，具体手机启动时间待用户安装反馈，不承诺固定秒数。

本地验证通过：11 项生产启动/复用与认证 RPC、44 项生产空闲调度/真实 Node 子进程取消、36 项工具环境及回执检查，Android API 28/34 编译和全部本地测试。成品 APK 安装闸门、完整 CI 与公开下载核验完成后补记结果。
