0.31.0 完成模型中心实时目录、原生返回导航与英文体验维护，继续兼容 0.30.0 的签名、数据与运行包升级路径。

## 模型中心

- Command Code 与 DeepSeek 官方直连的模型选择器改为认证读取各自上游 `GET /models`，不再把 App 本地预设直接显示为在线列表。
- 每次打开选择器都会读取最新目录，并提供手动刷新、模型 ID 搜索、加载状态和明确的网络错误分类。
- 上游响应决定可见模型；当前运行环境的能力目录只补充图片与推理能力并判断兼容性。
- 上游新增但能力信息不足的模型会显示原因并暂时禁用，避免模型可见却在真实会话中失败。
- 新模型和首次配置必须完成成功的实时读取；临时断网时仅允许原样保留既有服务商与模型。
- 密钥变化会立即废弃对应服务商的内存目录，旧异步请求不能覆盖新结果。

## 导航与英文

- 模型中心新增“返回工具与设置”，模型选择器新增“返回模型中心”。
- Android 返回键与边缘返回手势现在和页面可见按钮走同一父级路径。
- 设置首页、任务中心、会话管理、显示与语言、更新、数据、项目与诊断页不再因外侧点击或系统返回而丢失导航上下文。
- 补齐核心原生设置链路的英文文案，并新增完整 `README.en.md`。
- 中文 README 同步重写，补充安装、模型中心、项目、文件、更新回滚、隐私、架构、测试和已知限制。

## 安全与兼容

- 模型目录请求只执行只读 GET，不发送提示词，不记录 API Key、请求头或响应正文。
- 不自动猜测或写入未知模型能力，不新增高权限 `JavascriptInterface`。
- 包名、正式签名、用户数据目录、payload-v9、minSdk 24 与 targetSdk 28 不变，可从 0.30.0 直接覆盖安装。
- 会话、密钥、项目、任务历史和共享工作区不会因覆盖安装被清除。
