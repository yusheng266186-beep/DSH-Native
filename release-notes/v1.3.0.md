# 1.3.0 手机操控

<!-- dsh-doc-status:start -->
> 版本记录：标题版本对应本次发布，原始变更内容保留，不覆盖为新版说明。 已发布 stable：**1.3.1**；源码：**1.3.1**；源码运行包：`payload-v15`；固定 DSH：`0.2.2-rc.1`（上游候选版）。[统一进度与验证边界](../docs/STATUS.md)。

在「设置 → 数据与扩展 → 手机操控」开启系统无障碍服务，再确认开始本次操控。回到聊天后，可以请 DSH 读取当前界面、打开应用、点击、长按、输入、滚动、滑动，以及使用返回、主页和最近任务。Android 11+ 支持单张截图，有视觉能力的模型可读取。

操控默认关闭，浮动按钮可暂停或停止。熄屏、服务断开、内核重启或闲置三分钟后结束。屏幕文字和截图可能提供给所选模型，密码和系统授权由用户操作。无障碍树与输入能力取决于目标应用和 ROM。

采用 Android 公开接口独立实现，交互参考 [DSH Go 手机操控指南](https://github.com/ccch1mneyyy/dsh-Go/blob/main/docs/guide/zh/04-phone-control.md)。继续使用 DSH 0.2.2-rc.1 / payload-v15。自动检查覆盖授权状态、操作参数、DSH 工具调用及签名 APK。实际手机操控待真机验证。
