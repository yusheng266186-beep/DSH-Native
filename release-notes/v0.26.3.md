# DeepSeek Harness Native 0.26.3

<!-- dsh-doc-status:start -->
> 版本记录：标题版本对应本次发布，原始变更内容保留，不覆盖为新版说明。 已发布 stable：**0.33.6**；源码：**0.33.7**；源码运行包：`payload-v12`；固定 DSH：`0.2.0-rc.2`（上游候选版）。[统一进度与验证边界](../docs/STATUS.md)。
<!-- dsh-doc-status:end -->

本版合并阶段四 E/F 与发布前缺陷清理，重点改善任务状态、设置入口、交互反馈和长时间运行稳定性。

## 用户可见改进

- 通知栏适配空闲、运行中、等待批准、网络异常和状态同步，运行任务使用系统计时器持续显示时长。
- 侧边栏收起时，DSH 自带“设置”不再被 App 设置入口误接管。
- 原生工具面板增加分层进入、设置前进/返回、按钮按压与水波纹、选择确认和长任务持续反馈。
- 应用内更新只有在系统安装器真正打开后才显示“等待确认”；缺少安装权限时会明确提示授权后重试。

## 修复

- 修复网页主题切换导致 Activity 重建后，旧看门狗、日志线程、WebView 和静态日志回调长期残留的问题。
- 修复崩溃记录器在每次界面重建时重复套接，导致旧界面无法释放和崩溃日志重复写入的问题。
- API 密钥输入框显式退出 Android Autofill，避免部分输入法把密钥当作登录密码保存或推荐。
- 更新/分享 Provider 只接受明确白名单路径，未知 URI 不再误回退到更新 APK。
- Activity 销毁时正确收尾文件选择回调、退出面板和 WebView 资源。

## 兼容性

- 包名、数据目录、工作区、会话、运行包和更新通道保持不变。
- `minSdkVersion 24`、`targetSdkVersion 28` 保持不变。
- 使用与现有正式版相同的签名，可从 0.26.0 及同签名测试版直接覆盖安装。
