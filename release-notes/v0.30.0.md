0.30.0 合并阶段五 A 至 D：任务恢复、文件与会话工作流、模型中心，以及更新回滚、诊断和多设备适配。

## 新增

- 任务中心：持久化运行时间线、连接状态、后台完成提醒和同源草稿恢复。
- 文件工作流：多选复制/移动、可恢复回收站、图片预览；会话搜索和归档继续使用 DSH 官方界面。
- 模型中心：Command Code / DeepSeek 官方服务商、只读连接检测、模型搜索、思考强度与项目级默认模型。
- 新安装模型向导可中断恢复；升级用户不补弹，不改写已有会话。
- 运行包更新前保存上一套 DSH / 工具链；更新失败自动恢复，成功后可从设置手动恢复。
- ZIP 诊断包一键分享，包含设备、布局、WebView、网络、通知、任务、运行环境和回滚状态及脱敏日志。

## 体验与兼容

- 原生触摸目标提升到 48dp，标题与状态增加屏幕阅读器语义。
- 大字体或窄屏自动纵向排列底部操作；对话框适配手机、横屏和平板。
- WebUI 尊重“减少动态效果”，提高触摸操作目标，同时排除滑动开关，避免控件再次被压扁。
- 加固 tar.zst 解压路径和符号链接边界，快照恢复保留可执行位、长文件名和链接。

## 安全与升级

- 回滚只处理 `dsh` / `tools`，绝不覆盖 `.dsh` 会话、密钥、附件、项目或工作区。
- 诊断包不包含配置、凭据、会话正文、附件和项目文件，日志会再次脱敏。
- 不新增高权限 JavascriptInterface，不绕过 DSH 调用私有 RPC。
- 包名、正式签名、用户数据目录、payload-v9、minSdk 24 与 targetSdk 28 不变，可从 0.26.3 及阶段五候选直接覆盖安装。

## 验证

- 1036 项纯逻辑断言全部通过。
- WebUI 入口、状态探针、草稿恢复和会话状态模拟全部通过。
- 运行环境快照/恢复真实覆盖可执行位、长文件名、符号链接和目录穿越防护。
- 正式 APK 由 GitHub Actions 构建，并在发布前强制核对线上签名、版本、包名、SHA-256 与两条下载路径。

完整设计、风险和真机清单见 `docs/PHASE5D-ROLLBACK-DIAGNOSTICS.md`。
