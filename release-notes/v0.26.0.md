## v0.26.0 测试版

<!-- dsh-doc-status:start -->
> 版本记录：标题版本对应本次发布，原始变更内容保留，不覆盖为新版说明。 已发布 stable：**0.33.0**；源码：**0.33.0**；源码运行包：`payload-v11`；固定 DSH：`0.2.0-rc.2`（上游候选版）。[统一进度与验证边界](../docs/STATUS.md)。
<!-- dsh-doc-status:end -->

这是阶段一、二、三合并后的真机验收版本，不会推送给稳定通道用户。

- 手机、横屏和平板使用响应式布局，对话框、输入框、按钮和长代码块更适合触控。
- 增加命名项目与独立工作区，保留原默认工作区，不迁移或删除已有文件。
- 从其他 App 分享文件、多个文件或文本后，可直接创建 DSH 任务；页面未就绪时自动排队。
- 插件启用前显示能力与风险，授权绑定当前插件版本和内容，更新后需重新确认。
- 增加稳定版/测试版更新通道；本版本作为 GitHub Prerelease 发布。
- 包含阶段一的稳定性、安全与更新链路加固，以及阶段二的新手引导、工具入口、分类设置与中英文外壳。

安装前建议先用 App 内“配置备份”导出关键配置。测试时若遇到问题，请导出诊断包，
并注明机型、Android 版本、当前项目、操作步骤和是否为覆盖安装。
