# 0.36.0

<!-- dsh-doc-status:start -->
> 版本记录：标题版本对应本次发布，原始变更内容保留，不覆盖为新版说明。 已发布 stable：**0.36.0**；源码：**0.36.0**；源码运行包：`payload-v13`；固定 DSH：`0.2.1-rc.3`（上游候选版）。[统一进度与验证边界](../docs/STATUS.md)。
<!-- dsh-doc-status:end -->

- 语音面板整合到 DSH 输入框，跟随深浅主题，提供真实音量、计时、临时转写预览、结束与取消。长内容可滚动，短横屏压缩装饰区域，减少动态效果时关闭过渡。
- 通过公开 RecognitionService 直接识别；默认引擎未配置时可连接系统语音窗口同一提供方的公开服务，插件详情支持检测和选择实际引擎。
- 默认不再自动弹出系统语音框。页面内服务不可用时保留说明、重试、设置与“使用系统语音”的手动入口，保留原来的可用识别路径。
- 临时文字不改草稿，最终结果仍只填草稿，不自动发送；权限、取消、超时、晚回调及诊断隐私保护继续保留。

覆盖安装后重启内核。仍使用 payload-v13、原包名与签名，不重下载运行包或清除数据。Android 授权/隐私提示和外部识别窗口由系统/提供方绘制；只有窗口而没有公开可连接识别服务的手机，仍需手动窗口或配置兼容引擎，不能承诺所有设备均可无窗口识别。

自动回归覆盖生产原生控制器的边界、语音组件及真实 WebUI 多尺寸布局；未做真机录音或 ASR，继续由用户安装调试。

Integrates a themed dictation panel into the DSH composer with real audio levels, elapsed time and interim previews. Binds validated public recognition services and offers engine selection. System speech windows now require an explicit user action; providers exposing only an activity cannot be restyled or hidden by DSH. Final results only fill the editable draft. Keeps the existing runtime, signature and user data.
