- CodeBuddy 使用手机内置的官方 SDK 0.3.291 / CLI 2.176.0，解决原直接 API 路径遭 11128 拒绝的问题。已有 API Key 保留，安装覆盖后重启内核。
- 使用官方 CLI 代理行为，DSH 提供界面、会话和工具权限。内置 CLI 工具禁用，工具调用交回 DSH；实际完成对话、写文件、读回及回复保存。请求 max 交给官方 SDK，不保证所有模型均接受。
- 手机设置分类改用原 DSH 菜单；旧面板按语义重排为设置行与分组，长标签、缩放、项目范围等选项改用原菜单，导入连接使用原设置弹层，修复挤压与嵌套控件间距。
- 连接检查改为真实 CLI 短请求（可能使用少量额度），与不调用模型的目录刷新明确区分。SDK 归档与版本校验、取消、超时、流式去重、工具 Schema、图片转发和私有状态分享边界补齐。

APK 因内置 CLI 增大约 45 MiB；首次使用展开约 192 MiB，建议预留约 300 MiB 供准备与 CLI 私有缓存使用。无需电脑、Termux 或额外服务。

在独立临时工作区，用真实账号验证 DSH → 内置官方 CLI → DSH write/read → 回复存储；Android 平台选择边界也完成该流程。自动回归使用合成凭据，不调用付费模型。完整 Android CI、签名与发布检查通过后发布；按用户要求不做真机验证。
