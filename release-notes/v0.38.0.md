# 0.38.0

<!-- dsh-doc-status:start -->
> 版本记录：标题版本对应本次发布，原始变更内容保留，不覆盖为新版说明。 已发布 stable：**1.1.1**；源码：**1.1.1**；源码运行包：`payload-v14`；固定 DSH：`0.2.1-rc.3`（上游候选版）。[统一进度与验证边界](../docs/STATUS.md)。
<!-- dsh-doc-status:end -->

- 设备设置全面并入 DSH WebUI：通用、模型、会话、任务、文件、数据、更新和诊断共用原设置导航、控件、主题与确认层。硬件返回先处理设置，旧设备维护入口保留。
- 文件预览和交付卡增加编辑、其他应用打开及 Android 系统分享；文本可以直接新建/修改/保存，Office 等格式交给支持的应用编辑。普通打开/分享只读，明确编辑才授予所选文件的写权限。
- 修复文件工具栏换行后被正文遮挡、文件列表只追加首批、加载期间误操作旧条目、只读文本判定和分块读取失败后误编辑截断内容等细节，保留编码、原子保存与未保存保护。
- 接入本机 CodeBuddy CLI 配置的私人加密导入，密钥保存到内核凭据，发送请求时再解析认证头；21 项模型目录明确标注来自 CLI 2.174.0 元数据，实际模型/Max 权限以服务端为准。
- 删除 CommandCode 面板、默认配置与用量查询，清理旧路由和凭据引用，迁移仍使用旧路由的默认/项目选择；保留其他服务商、账号、历史与项目数据。

覆盖安装后重启内核。CodeBuddy 私人连接在模型设置中导入一次；公开 APK 不包含个人密钥。文件的外部编辑需要支持 content URI 的应用，部分应用只支持另存为。

自动检查包括真实 DSH WebUI/内核消费、Android Java/DEX/资源/签名以及 API 边界替身；按约定不做真机验证，由用户下载安装调试。

Integrates device settings into the original DSH WebUI, adds file editing/open-in-app/Android sharing, fixes mobile toolbar and detached-view loading defects, and supports private encrypted CodeBuddy CLI imports. Removes the retired provider configuration while preserving independent accounts, projects and history. Restart the core after installing; import the private connection once in Models. External editing requires a compatible Android content-URI editor.
