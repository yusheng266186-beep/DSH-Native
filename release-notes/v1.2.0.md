# 1.2.0：升级 DSH 0.2.2-rc.1，沿用官方移动端布局

<!-- dsh-doc-status:start -->
> 版本记录：标题版本对应本次发布，原始变更内容保留，不覆盖为新版说明。 已发布 stable：**1.1.6**；源码：**1.2.0**；源码运行包：`payload-v15`；固定 DSH：`0.2.2-rc.1`（上游候选版）。[统一进度与验证边界](../docs/STATUS.md)。
<!-- dsh-doc-status:end -->

将 DSH 从 0.2.1-rc.3 升至官方于 2026-11-04 发布的最新候选版 0.2.2-rc.1。App 正式通道与上游候选级别分别记录。[完整上游说明](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.1)。

- 优先采用官方手机/平板视口、抽屉侧栏、设置导航、模型菜单及多语言界面。撤下新版上的旧 480px 缩放、侧栏行为和整套布局覆盖，保留 Android 所需扩展。
- 保留新版引用聊天文本、复制会话 Markdown、发送失败保留草稿与附件、即时上传图片、文件导航和工作步骤显示等功能。实验性新增插件继续由用户选择启用。
- 修复新版侧栏收起时旧启动检测无法正确识别首页的问题；仍要求可见输入区与真实内核连接。
- Android 文件编辑、打开与分享收进官方预览栏内的紧凑菜单，不再挤压或扩大官方工具栏。仅补充实际测出的设置文档按钮大字体换行、预设卡片提示边界。
- 保留 CodeBuddy 1M 上下文和 Android 文件、语音、后台服务、运行包校验与回滚。迁移官方已移除的独立工作树条目，保留其他插件配置；不自动启用替代实验性插件。

使用固定官方 npm 归档及完整锁文件，运行包预适配后发布为 payload-v15。四个工具分片沿用已验证的原字节，常规升级只下载 DSH 分片；保护历史、凭据与项目。

验证包括旧内核写入的普通/压缩历史在新内核读取与续写、真实 DSH/官方 SDK 工具调用、启动首屏、模型与设置、多语言及触屏浏览器回归；Android 构建、签名和成品事实以本版 Actions/Release 为准。没有手机或模拟器实测，浏览器验证不能替代实际 ROM、键盘、语音和后台行为验收。
