## v0.24.1 —— 0.24.0 的收尾修正

0.24.0 发布时，其中一个文件组还在收尾，因此这一版补上它最后的修正，
并修掉一个会让构建间歇性失败的问题。

### 功能修正

* **删除文件夹时若面板已关闭，不再留下一个永远转圈的进度框**
* **浏览器关闭后再触发的刷新不再抛异常**（编辑器保存后回调 `refresh()`
  时浏览器可能已关，此前会抛 `RejectedExecutionException` 被吞掉）
* **列表淡入动画此前等于没做**：程序创建的 `AlphaAnimation` 时长默认是 0
  （AOSP 里 `mDuration` 无初值），照抄 `new AlphaAnimation(0f, 1f)` 是瞬切 ——
  现在显式设 200ms
* 面包屑滚动目标改为内容宽度（固定值会把深路径的当前目录留在屏幕外）
* 文件列表按钮「隐藏文件」在本机 400dp 宽度下会被省略成「隐藏文…」，
  已为该按钮单独收窄字号与内边距

### 构建

* **修掉一个间歇性失败**：构建需要知道"上一个发布版是哪个 tag"来取内置
  运行负载，此前只用**未认证**的 GitHub API —— 它按 IP 限流 60 次/小时，
  而 CI runner 是共享 IP，于是同一份代码可能前一天能过、第二天失败。
  现在优先用带 token 的 `gh`，未认证 API 仅作兜底。

### 说明

0.24.0 本身是可用的（CI 编译与全部断言通过），这一版只是把收尾补完。
安装：通知栏 →「设置」→「检查 App 更新并安装」。
