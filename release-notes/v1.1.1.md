修复 1.1.0 打开即显示 `Invalid APK asset index`、重启无效的问题。

组件安装器的文件名规则漏掉了 Android 自带库 `libc++_shared.so` 中的加号，导致正常索引被拒绝。新版修正合法字符规则，继续拒绝目录穿越、绝对路径和分隔符别名；构建端使用同一文件名约束。

增加成品 APK 验收：签名完成后，使用实际 Java AssetInstaller 读取 APK 并安装所有组件，验证重启复用、无回执旧环境迁移、缺失 C++ 库恢复和用户目录保留。任何一项失败都会阻止构建通过。

保持原签名、包名和 payload-v14，可直接覆盖安装，历史、项目、附件及账号配置保留。此修复不需要删除数据或重装运行包。仍按约定不做真机或模拟器验证。

完整 CI：[40484600018](https://github.com/yusheng266186-beep/DSH-Native/actions/runs/40484600018)。公开下载 APK 再次通过 76 项实际组件安装检查和原签名核验。APK SHA-256：`a0e40cd2bb06ef921940e0408451adc1191b7dc58a62161775dbb0011a74d66b`。
