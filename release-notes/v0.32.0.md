- DSH 内核升级到官方最新 0.2.0-rc.2（上游候选版），运行包升为 payload-v10；包含模型搜索、计划审阅、Agent 预设和模型兼容性修复。
- 保留实时模型目录、思考强度、视觉能力和现有用户配置。升级只下载变化的 DSH 分片，工具链保持不变，更新前保留回滚快照。
- 修复启动认证探测未携带 Cookie，导致已有服务被误判不可用、重复启动的问题。
- APK 引用新运行包时首次启动直接应用升级；修复实际解压空间被低估的问题。
- 加固文件锁和无硬链接文件系统的会话写入，清理上一内核废弃文件，保留历史和凭据。
- 修复 main 构建提前校验未发布版本、旧测试通道运行包误判以及签名参考误选 payload Release 的问题。

已通过纯逻辑测试、真实归档解压、92 个模型等级和离线请求参数、视觉能力、会话落盘恢复及 Web 服务启动回归。Android 构建和发布流程继续核对原签名与下载路径。
