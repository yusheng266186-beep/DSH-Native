# 1.3.1 首次配置修复与测速诊断

<!-- dsh-doc-status:start -->
> 版本记录：标题版本对应本次发布，原始变更内容保留，不覆盖为新版说明。 已发布 stable：**1.3.0**；源码：**1.3.1**；源码运行包：`payload-v15`；固定 DSH：`0.2.2-rc.1`（上游候选版）。[统一进度与验证边界](../docs/STATUS.md)。

修复首次安装因读取不存在的旧配置导入记录而启动失败的问题，保留已导入的用户模型目录。CodeBuddy 运行日志增加首末输出跨度和收尾时间，方便定位实际输出、宿主处理与 CLI 收尾的区别；不修改代理规则、模型、SDK、内核或聊天页的速度统计口径。

同一账号与模型的直连测试中，正式 1.3.0 APK 在 Android 15 ARM64 模拟器的两个新会话显示 150、121 tok/s，未复现用户真机固定不足 80 的情况。模拟器成绩不能替代 Android 17 真机结论。测试环境、首次安装复现及验证边界见 [测速记录](../docs/PERFORMANCE_2026_11_05.md)。
