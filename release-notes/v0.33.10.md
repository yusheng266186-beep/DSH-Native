将模型列表更新移入原生 App 设置，并接入内核的 DeepSeek 账号登录。

- 在 **App 工具 → 模型中心** 更新模型列表，侧栏保留一个 App 工具入口。
- 新增 **DeepSeek 账号登录与管理**：浏览器授权、状态刷新、重新打开、取消和退出；支持账号模型与全局/项目默认。
- 服务商改为整行纵向选择，API Key 输入只显示当前选中的服务商，账号路线无需填写密钥。
- 修复内核导入配置后原生设置与项目切换遗漏当前模型的问题；配置备份现在包含 active Web profile。
- API Key 通过内核保存，避免覆盖新账号授权；登录参数脱敏，强化本机地址识别和异步回调、取消处理。
- 切换项目时将未知任务状态纳入中断提示，配置读取、保存与模型目录请求离开主线程。
- 内核端口或令牌变化后丢弃旧原生连接，首次引导移除过时的空间估算。
- 启动时核对模型配置已被内核采用，避免过早读取半成品模型目录；系统日志也对登录参数脱敏。

保留既有包名、签名及 payload-v12，可覆盖安装。账号回归使用真实内核和合成平台；真实平台授权及新增原生页面的手机体验需安装后确认。没有发送付费模型提示词。

## English

Move **Refresh models** into **App tools → Model center** and integrate the core's DeepSeek account sign-in.
Authorize through the system browser, resume or cancel sign-in, sign out, and use account models in global/project defaults.
Providers use full-width rows with only the relevant API key input visible.

Read the active core profile after legacy configuration import, apply project model overrides correctly, and include the active
Web profile in encrypted backups. Save API keys through the core to retain account grants. Redact authorization parameters,
validate loopback origins, and run configuration/network work in a bounded background queue. Unknown task state now receives
the project-switch interruption warning.
Discard stale native connections after core port/token changes and remove obsolete first-run storage estimates.
Confirm imported model settings before opening the WebUI and redact authorization values in Android system logs.

Uses the existing package, signing key and payload-v12. Account tests use the real core with a synthetic local platform;
real-platform authorization and new native-page device acceptance remain separate. No billed model prompts were sent.
