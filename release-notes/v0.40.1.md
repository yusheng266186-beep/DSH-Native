# 0.40.1

> 版本记录：标题版本对应本次发布，原始变更内容保留，不覆盖为新版说明。 已发布 stable：**1.1.1**；源码：**1.1.2**；源码运行包：`payload-v14`；固定 DSH：`0.2.1-rc.3`（上游候选版）。[统一进度与验证边界](../docs/STATUS.md)。

- 加载页换成随 DSH 主题变化的三点小动画。真实内核连接与界面首帧均就绪后，在当前周期结束时进入；版本/切片更新继续循环并显示实际进度。
- 优先复用已经完成本版准备的后台内核，减少重复的 Node 自检、补丁扫描和配置准备。升级、缺文件、工作区/分片变化等情况仍完整处理。
- 移除等待服务时反复请求首页和重载状态页的开销，准备好后更快加载网页；新增私有编译缓存，后台更新检查移到界面出现之后。
- 后台暂停动画和界面超时，无动画设置立即交接，失败直接显示日志与重试。修复把上游无尺寸 slot 当作“未绘制”的问题，清理旧回调和遮罩触摸，防止重复注册网络监听或重建后持有旧 Activity。
- 保留 0.40.0 的后台返回重连、聊天调用优化与统一设置；不改变包名、签名、数据或运行包版本。由用户安装验证手机实际启动表现。

验证：23 项启动逻辑、21 项原生 View 边界、12 项实际内核/浏览器/缓存检查及完整 JVM/脚本通过；完整 Android CI、旧 WebUI 和发布校验以本版工作流为准。没有真机测速，桌面检查不代表手机启动时间。
