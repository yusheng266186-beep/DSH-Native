# DSH Native 1.1.0

<!-- dsh-doc-status:start -->
> 版本记录：标题版本对应本次发布，原始变更内容保留，不覆盖为新版说明。 已发布 stable：**1.0.0**；源码：**1.1.0**；源码运行包：`payload-v14`；固定 DSH：`0.2.1-rc.3`（上游候选版）。[统一进度与验证边界](../docs/STATUS.md)。
<!-- dsh-doc-status:end -->

围绕主题切换卡死、启动反复准备和旧异步回调，重构 Android 应用主干。

- 深浅色与系统主题改为原位更新，保留现有页面、输入光标、草稿、弹层和滚动。
- 独立启动协调器统一受理、环境锁、取消和回调代次；重启受理后才执行停机，运行包更新与恢复不再与启动交错。
- 19 项固定内核适配前移至 payload-v14 构建阶段。手机启动不再遍历、改写这些内核模块；工具路径单独准备。
- 新组件安装器按实际内容更新，校验后原子替换，复用未变的 Node/动态库。临时命令有超时和取消，诊断日志后台写入并统一脱敏、限长和轮转。
- 浏览器由单一模块管理；横竖屏和分屏更新现有 viewport，保持 480 窄屏下限并保留草稿。设置入口、原生面板与返回分类统一管理，过期页面回调不再弹出旧界面。
- 删除旧主题重建计时器、启动期源码补写、重复下载实现、无调用的旧凭据写入辅助方法和反射 API 16 权限路径。

保持原包名与签名，可覆盖安装；项目、历史、附件和账号数据保留。已适配的 1.0 运行环境有逐组件兼容检查，可用于离线升级/回滚；未完成适配的旧环境仍须更新运行包。

固定 DSH 0.2.1-rc.3 和 CodeBuddy 官方 SDK/CLI 接入不变。发布经过完整 Android CI 与公开资产/签名校验；按约定不做手机或模拟器测试，也不发送付费模型提示词。手机启动耗时和 ROM 行为仍请安装后反馈。
