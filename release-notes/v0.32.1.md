# v0.32.1

<!-- dsh-doc-status:start -->
> 版本记录：标题版本对应本次发布，原始变更内容保留，不覆盖为新版说明。 已发布 stable：**0.32.1**；源码：**0.32.2**；源码运行包：`payload-v10`；固定 DSH：`0.2.0-rc.2`（上游候选版）。[统一进度与验证边界](../docs/STATUS.md)。

- 按用户要求，为 Command Code 全部模型统一增加 max 请求选项，包括 Space Bunny Alpha、原先没有 max 的模型和以后同步的新模型；DeepSeek 官方直连保留 max。
- 保留模型原有等级；没有已声明档位的模型保留服务商默认路径。升级、目录刷新与选择保存不再移除 max，也不将 max 替换成 high、xhigh 或其他值。
- 聊天框与原生模型中心显示 Max（请求）并说明接口可能拒绝或忽略该参数。上游错误正常显示，不自动降级或重试其他档位。
- 增加真实 DSH Host 模型目录、94 个模型的中英文聊天选择与保存投影回归，以及 92 个 Command Code 模型的离线请求体校验。测试不调用付费模型。

此版本开放的是发送 max 的能力，不保证所有模型实际支持更高推理预算。继续使用 payload-v10 / DSH 0.2.0-rc.2 与原签名，可覆盖安装。
