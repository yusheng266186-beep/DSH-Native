# DSH Native 1.1.5

一体化鲸鱼动画，并继续减少首屏等待。

- 鲸鱼由完整矢量轮廓一次绘制，尾部通过连续形变自然摆动，去掉身体和尾巴的拆分拼接。眨眼直接改变原眼部留白，细化主题渐变、轻游、水波和气泡；每帧复用绘图对象。
- 首屏检测提前到页面提交可见内容时启动，保留完整加载回调兜底。设置入口和聊天输入区或可操作对话框已绘制、真实内核握手完成后即可交接，图片等非关键资源继续加载，不再必须等完整 load 结束。
- 合并 DOM 变化产生的首帧检测，减少初始化期间同步读取布局；布局诊断等首页可用、空闲后再安装。准备提示区分工具检查、配置同步、服务启动和聊天界面加载。
- 保留双帧与 Android visual-state 确认、断连撤回、后台暂停、减少动画及 180ms 过渡。分享任务在界面和连接真实就绪后再提交。

沿用原签名、包名和 payload-v14，可覆盖安装。配置、历史和项目保留。

本地完整 JVM、JS、Python 回归通过；包含 247 项轮廓/循环/边界检查、原品牌矢量坐标一致性、30 项生产动画生命周期与绘制检查、14 项真实内核/浏览器启动回归。浏览器用例故意阻塞图片，验证完整加载尚未结束时也能完成真实界面绘制检测；前后台、旧代次、无界面与隐藏界面仍不误报就绪。深浅色桌面绘制预览已检查。

用户反馈最新版等待约 20–30 秒。本版确认并去掉了一条额外等待路径，尚无手机证据证明全部等待已消除，不承诺固定提速秒数。未做真机或模拟器测试；完整 Android CI、签名及公开安装包以本版 Actions 与正式发布清单为准。
