- 修复点击麦克风立即错误 5 时缺少兼容路径：核对真实默认识别服务；默认未配置或服务启动失败时，尝试系统语音窗口。端侧、默认和系统窗口按有界顺序处理，不循环重试。
- “结束并识别”只在准备好后显示，处理中不重复停止；启动无回调独立超时，取消、切换会话或退后台后不执行旧回退。
- 系统窗口的取消与识别错误分别显示，超长转写独立提示；失败面板提供系统语音设置入口。
- 长错误提示和保留转写在有界区域滚动，恢复按钮独立排列，避免短横屏被正文挤出。
- 诊断保留失败阶段、异常类和尝试路径，不记录音频或识别文字。新增执行生产原生控制器的边界回归，补充语音组件与触屏场景。

覆盖安装后重启内核再试，无需卸载或重新下载运行包。仍沿用 payload-v13 与既有签名。实际语音能力取决于手机已提供的 Android 识别服务/窗口；只有输入法私有语音功能的系统不一定开放这些接口。按用户约定不做真机验证，由用户安装调试。

Adds a bounded system speech window fallback for immediate Android speech client error 5, validates the selected default recognition service, prevents premature/duplicate stop calls and preserves actionable startup diagnostics. Tests execute the production controller with Android boundary fakes and do not claim real device audio/ASR validation.
