# 0.39.1

<!-- dsh-doc-status:start -->
> 版本记录：标题版本对应本次发布，原始变更内容保留，不覆盖为新版说明。 已发布 stable：**1.1.5**；源码：**1.1.5**；源码运行包：`payload-v14`；固定 DSH：`0.2.1-rc.3`（上游候选版）。[统一进度与验证边界](../docs/STATUS.md)。
<!-- dsh-doc-status:end -->

- 精简手机内置 CodeBuddy SDK：归档约 45 MiB 降至约 7.5 MiB、展开约 192 MiB 降至约 51 MiB。移除桌面网页界面、未使用的服务端组件和跨平台外部工具，保留官方 headless 运行文件及许可，不改写认证逻辑。
- DSH 执行工具期间提前准备下一次独立官方 Session，并启用私有 Node 编译缓存。预热不发送模型提示词，最多一个、10 秒有效，仅相同凭据、模型、强度和工具配置可领取一次；失败与取消不会重发请求。
- 精简包实际完成 DSH 写文件、读回和回复保存。自动回归覆盖 Schema、流式去重、取消、超时、错误脱敏、体积预算和预热配置隔离；完整 Android CI 通过后发布。

安装覆盖后在更新与维护重启内核，现有 CodeBuddy Key 继续使用。首次准备建议保留约 200 MiB 空间。优化针对本地准备和启动开销，网络、模型与思考强度仍影响对话耗时；没有降低 max。按用户要求不做真机验证。
