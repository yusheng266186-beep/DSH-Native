## 原始阶段记录

本阶段承接阶段一的稳定性、安全与更新链路加固，重点降低首次使用门槛，
让原来依赖长按和通知栏的功能可直接发现，并减少设置页滚动、误触和无效重启。

本阶段不改变 `targetSdkVersion = 28`，不迁移签名密钥，不发布新版，也不直接合并主分支。

> 阶段四 A 修订：真机反馈确认右上角悬浮入口会遮挡 DSH 页面。该入口已从原生覆盖层移除，
> 并迁移到 DSH 侧边栏；当前实现和验收要求以 `PHASE4A-WEBUI-TOOLS.md` 为准。

## 已完成

- 新安装在下载约 117 MiB 运行包前显示三步引导，明确空间、联网、权限和账号配置。
- 引导支持跟随系统、中文和 English；既有 `.dsh` 数据的升级用户自动跳过，不补弹新手流程。
- 运行环境就绪后，新用户会自动进入「账号与模型」，不再需要先理解 DSH 网页导航。
- WebView 右上角增加始终可见的「工具」入口；通知栏和桌面快捷方式仍可作为备用入口。
- 原单页设置拆为「账号与模型、显示与语言、更新与维护、数据与扩展、诊断与日志」五类任务页。
- 原生工具外壳增加轻量中英文层，覆盖新引导、工具页、主要操作和桌面快捷方式；
  DSH 网页继续使用自己的语言设置，文件名、模型名和原始诊断输出不会被误翻译。
- 账号页没有实际改动时直接返回，不再无意义重启 agent；有任务运行时仍会在重启前二次确认。
- 发布脚本从真实 APK 和 payload 清单生成版本、下载链接、体积和 SHA-256；CI 阻止元数据漂移。
- `run_tests.sh` 在缺少 `javac` 启动器、但存在 JDK compiler 模块时也可运行，避免本地检查被弱化。

## 自动验证

- 16 个纯 Java 测试程序，共 593 项断言；新增语言解析、回退、动态文案和升级用户引导判定测试。
- Java 全量语法与引用检查、资源 XML、纯逻辑层 Android 依赖、系统 `AlertDialog` 和源码 emoji 闸门。
- 发布元数据一致性、Shell 语法、Python 语法和 git 空白错误检查。
- 完整 Android `javac`、DEX、aapt2 资源/清单和 APK 签名检查由 GitHub Actions 执行。

## 已知边界与风险

- 中英文层优先覆盖原生导航与高频操作；底层原始日志、错误详情和第三方 DSH 网页内容可能保留原文。
- 首次引导和分类设置属于 Android UI，普通 JVM 无法验证布局、软键盘遮挡、触控目标和 ROM 权限弹窗顺序。
- 右上角工具入口采用小面积悬浮按钮，需要在窄屏、横屏和网页顶部操作密集的页面确认不会挡住关键控件。
- 跟随系统模式当前把非中文系统回退到 English；若要增加更多语言，需要单独补齐文案和资源。
- 仓库历史中的发布密钥仍是阶段一记录的独立迁移问题；本阶段没有扩大或改变其影响。

## 真机验收步骤

1. **全新安装**：清除 App 数据后启动，确认引导在下载前出现，117 MiB / 550 MiB 提示准确，且无法误触关闭。
2. **语言切换**：在引导中依次选择跟随系统、中文、English；进入后再从「显示与语言」切换，确认立即生效且 agent 不重启。
3. **首次闭环**：开始配置并完成下载，确认自动打开「账号与模型」；输入测试密钥和模型后保存，服务正常启动。
4. **升级兼容**：保留已有 `.dsh` 数据覆盖安装，确认不出现首次引导，原密钥、模型、工作区和会话仍可用。
5. **入口与布局**：检查竖屏、横屏和系统大字体；确认右上角「工具」可见、可点击，不遮挡网页关键操作。
6. **分类功能**：逐页打开账号、显示、更新、数据和诊断；验证文件、加密备份、插件、日志、网络诊断及返回路径。
7. **无效保存**：账号页不修改直接保存，确认提示「没有需要保存的改动」，运行中的任务和 agent PID 不变。
8. **更新回归**：从「更新与维护」分别检查运行包和 App 更新；确认无更新、断网、校验失败时状态明确且旧环境可继续用。
9. **Android 版本矩阵**：至少在 Android 7、9 和当前主力设备各完成一次上述关键路径。

真机验收通过前，不合并主分支、不发布 APK，也不进行签名密钥迁移。
