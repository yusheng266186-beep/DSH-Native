# 手机文件操作

DSH 设置的“文件”、右侧文件树的“管理文件”、文件预览和交付卡共用文件操作入口。WebUI 继续使用 DSH 自带的导航、主题、按钮、输入和确认框。

| 操作 | 行为 |
|---|---|
| 查看 | 图片预览；文本只读且可复制；其余格式用系统应用打开 |
| 编辑 | 常见文本/代码直接在 DSH 编辑并保存；Office、图片等交给支持 Android 编辑 URI 的应用 |
| 其他应用打开 | Android ACTION_VIEW 与文件 MIME 类型，选择已安装应用 |
| 分享 | Android ACTION_SEND / 系统分享面板，支持发送至微信、邮件、网盘等已安装目标 |
| 新建 | 可以选择新建文件或文件夹；新文件创建后进入编辑器，同名文件不覆盖 |
| 其他 | 保留重命名、复制/移动、多选、回收站与恢复 |

普通打开和分享只授予读取权限。显式“编辑”使用独立 `/e/` content URI 和临时读写授权；所选应用可把内容写回原文件，不开放整个目录或永久授权。是否能原位保存取决于对方应用是否支持 content URI / ACTION_EDIT；有些应用只提供另存为。DSH 不把打开选择器当作已经送达或已经修改。

Provider 在每次打开描述符时复核现存常规文件和可写根。运行目录、越界软链、敏感凭据文件和无效模式拒绝写入；分享路由不能申请写描述符。Office 文档、表格、演示文稿等有正确 MIME 类型，避免全部被当作通用二进制。

文本编辑保留编码/BOM/换行和原子保存，检测打开后原文件变化；关闭/返回时保护未保存内容。较大文件只读预览，不把截断内容保存回原文。文件浏览器的只读位置不能进入写模式。WebUI 大文本使用分块传输，已有密码不回传；加载期间不操作旧文件行，多批列表通过主线程 Handler 完成，不依赖未附着的 Android View。

自动回归覆盖真实 DSH 预览 slot、文件操作路由、手机/横屏边界与 Java 控制器；Android Intent、URI 授权和 Provider 的保存模式使用边界替身，不启动真实手机应用。本轮按用户约定不做真机验证，WPS/系统编辑器等实际兼容性由用户安装反馈。
