## 归档状态与后续变更

本阶段对应实现已进入主分支。以下验收步骤、测试数量和发布限制保留当时版本语境；当前完成范围与未验证项目统一见 [STATUS](STATUS.md)。

## 原始阶段记录

本阶段基于阶段五 A 的 0.27.0 候选继续，验收版本为 `0.28.0`（`versionCode 2800`）。目标是补齐手机上最常用的文件整理闭环，并让 DSH 已有的会话搜索、归档与恢复更容易找到。包名、签名、数据目录、payload、minSdk 24 与 targetSdk 28 均不改变。

## 已完成

### 1. 文件多选与批量复制/移动

- 文件浏览顶部新增“多选”；选中后可复制、移动或批量移到回收站。
- 复制/移动采用“先选择项目，再导航到目标目录，最后粘贴”的手机文件管理器流程。
- 同名目标不会覆盖，自动生成 `名称 (1).扩展名`；复制先写隐藏临时目录，再一次性提交。
- 移动优先使用同卷原子重命名；跨目录无法直接重命名时才执行复制并删除源项。
- 源和目标均受现有规范路径白名单约束；系统目录、运行包和整个 `/sdcard` 继续只读。
- 拒绝把目录复制到自身内部，也不跟随符号链接递归复制。

### 2. 可恢复回收站

- 文件浏览中的“删除”改为“移到回收站”，单项与批量操作一致。
- 每个可写根使用同卷隐藏回收站，移动不复制大文件，保留原始路径和删除时间。
- 顶部“回收站”可恢复或永久删除；恢复时若原位置已有同名文件，自动保留两份。
- 元数据采用带版本和魔数的二进制记录；损坏、越界或跨根记录会忽略。
- 永久删除只存在于回收站内并需二次确认，避免文件列表误触造成不可恢复损失。

### 3. 文件预览

- PNG、JPEG、WebP、GIF 与 BMP 点击后使用原生图片预览，不再误送进文本编辑器。
- 预览在后台解码并按最长边约 1600 px 采样，拒绝空文件和超过 64 MiB 的图片，降低内存峰值。
- 文本仍沿用现有编码探测、二进制识别、大文件只读预览与原子保存能力。

### 4. 会话搜索与归档入口

- “工具与设置”首页新增“会话管理”。
- “搜索会话”聚焦 DSH 官方会话搜索框；“查看已归档会话”切换到官方“仅显示已归档”筛选。
- 归档、停止运行中任务、取消归档和历史内容搜索均继续由 DSH 官方组件负责。
- 仅按中英文无障碍标签寻找控件，不调用 `workspace.archiveSession` 等内部 RPC，不新增 `JavascriptInterface`。
- 若上游控件暂时未渲染，会给出“先展开侧栏”的可操作提示，不伪造成功。

## 自动验证

- `FileBatchTest` 覆盖复制、移动、递归目录、重名保留、白名单、复制到自身与符号链接。
- `FileTrashTest` 覆盖移动、恢复、重名恢复、目录永久删除、越界拒绝和损坏索引。
- `FilePreviewTest` 覆盖常用图片/文本类型与 64 MiB 解码边界。
- `SessionOrganizerTest` 覆盖中英文标签、搜索聚焦、归档筛选、失败标记和禁止私有 RPC；生成脚本同时经 Node 语法检查。
- 阶段五 B 接线闸门验证批处理、预览、回收站和会话管理实际被 UI 调用。
- 原有阶段一至五 A 的纯逻辑、WebUI 注入、发布安全与 Android 构建回归继续执行。

## 边界与未完成

- 暂不复制符号链接。Android 上不同存储后端对链接支持不一致，错误跟随可能越过白名单。
- 批量操作当前提供完成数量与日志中的逐项失败原因，不提供按字节的实时总进度。
- 回收站是本机本 App 内能力，不与云端同步；卸载 App 仍会清除私有目录中的回收站和用户数据。
- 会话搜索与归档依赖当前 DSH 官方中英文无障碍标签；上游改名时会安全失败并提示用户。
- App 不提供会话删除。归档保留日志和工作区归属，符合 DSH 的非破坏性会话模型。

## 真机验收

1. 从 0.27.0 候选覆盖安装，确认版本为 0.28.0，已有项目、会话、密钥、草稿和任务历史保留。
2. 在可写目录长按或点“多选”，选中多个文件与文件夹，复制到另一目录；确认内容完整且源项保留。
3. 再执行移动；确认源项消失、目标出现。制造同名文件，确认自动生成 `(1)` 且不覆盖。
4. 单项与批量执行“移到回收站”，确认列表消失；进入回收站恢复，确认回到原目录。
5. 原目录创建同名文件后再恢复，确认两个文件都保留；永久删除需二次确认。
6. 打开 PNG/JPEG/WebP 图片，确认比例正常、可滚动查看且关闭后文件未改变；文本文件仍正常编辑。
7. 在根目录或工具链目录尝试多选操作，确认只读提示且没有写入。
8. 打开“会话管理 → 搜索会话”，确认侧栏搜索框获得焦点并可搜索标题/历史。
9. 从会话菜单归档一个空闲会话，再打开“查看已归档会话”，确认可见并能取消归档。
10. 对运行中的会话尝试归档，确认 DSH 明确要求停止，不得静默隐藏仍在运行的任务。
