## 已确认的根因

消费 payload-v12 的实际 DSH 0.2.0-rc.2 Web profile 和前端，在触屏 Chromium
中应用 0.33.8 的原生 HTML 补丁。视口保持 480，比较同一个页面的补丁前后几何：

```css
@media(pointer:coarse) {
  button:not([role=switch]),[role=button]:not([role=switch]) { min-height:44px; }
}
```

这条规则强制扩大所有普通按钮的高度，上游明确的小尺寸控件因此变成长条。
文件标签本身只有一行高，20px 的关闭按钮变为 44px 后，居中的叉号落到了标题行下方。
此次移除错误的全局高度下限，恢复上游组件各自的尺寸。

| 控件 | 0.33.8 触屏实测 | 移除规则后 |
|---|---|---|
| 发送按钮 | 34 × 44 | 34 × 34 |
| 图片附件取消 | 18 × 44 | 18 × 18 |
| 文件附件取消 | 18 × 44 | 18 × 18 |
| 文件标签关闭 | 20 × 44，叉号落到下方 | 20 × 20，保持标题同行 |
| 折叠侧栏图标 | 36 × 44 | 36 × 36 |
| 添加附件、预览工具、侧栏工具 | 28 × 44 | 28 × 28 |
| 原图预览关闭 | 36 × 44 | 36 × 36 |

旧交接中“视口 480 大于屏幕 436 是挤压根因”的判断没有实测支持，此次证据指向
全局高度下限。也不能把“CSS Module 类名带哈希”理解为所有语义后缀都会消失：
实际包中有 `gSkjMW_remove` 等名字，但 `[class*=Card]` 仍不能命中文件卡片。
此次删除这些猜测类名的旧规则，不增加新 CSS 覆盖。后续生产补丁仍只使用实测的
`aria-label` / `data-*` 等稳定锚点，不绑定构建哈希或猜测名称。

## 保持有效的布局约束

- `MobileLayout.viewportWidth()` 窄屏下限维持 480；不再次改小导致整体放大。
- 保留设置页的窄屏纵向布局、导航横向滚动和开关尺寸约束。
- 不用全局元素选择器配合 `!important` 压倒上游组件。
- 不为每个图标再叠加“拉回方形”的覆盖；先移除造成拉伸的规则。
- 改动必须测量实际消费路径。Java 字符串断言和 APK 构建成功不能证明页面几何正确。

## 持续布局诊断

`LayoutProbe` 以前只在页面加载后扫描一次，先取十个最小控件，再把整段 JSON
截断为 900 字符。这会遗漏后来出现的附件、发送状态与文件标签。

当前探针通过 DOM 控件增删、ARIA 状态变化、点击、输入、文件变更、窗口尺寸变化
触发去抖测量；每次最多测量 200 个控件，优先测量发送、附件取消、关闭和文件工具。
输出最多 20 个控件，每条独立的 JSON 小于原生日志限制；同样的几何不重复输出，
页面隐藏时不扫描，pagehide 清理监听，pageshow 恢复。Activity 销毁或 WebView
已经替换后，延迟安装失效。

日志仅含固定动作名、实际 CSS 类名与尺寸。`移除图片 <文件名>` / `Remove file <name>`
会归一化为 `remove-image` / `remove-file`；不输出原始 ARIA、文件名、路径、正文、
附件内容或错误详情。原生端拒绝过大的单条记录，不截断 JSON。

探针不会修改 DOM、发送网络请求或调用模型。它是诊断辅助，不替代逐组件验收。

## 可重复运行的真实页面回归

```bash
bash scripts/run_tests.sh
bash scripts/check_model_consumer.sh
```

第一条运行 JVM 与实际生成 JS 的确定性模拟，覆盖延迟新增附件、控件优先级、
去重、输出上限、脱敏、节流、旋转、页面隐藏和生命周期清理。

第二条下载并校验源码引用的真实运行包，保留现有模型与内核回归，增加
`tests/js/mobile-layout-consumer.mjs`。测试启动真实 Host、交换启动令牌为 Cookie，
注册临时合成工作区，渲染实际生产前端和 Java 生成的 HTML 补丁。
Playwright / Chromium 只属于测试依赖，不进入 APK。

覆盖 320、360、436、600 宽度与 869 × 436 横屏，包含中英文、明暗主题；窄屏实际
CSS 视口仍为 480。检查空输入与输入后的发送区、长文件名、多文件加图片附件、
模型选择器与发送按钮的分隔、原图关闭、文件标签关闭的同行位置、预览工具、
设置边界、导航文字与开关。实际点击取消附件、关闭图片、关闭文件标签和返回设置。
负向对照重新加入旧 44px 规则，必须能复现发送、附件和文件标签的高度回归。
不发送模型提示词。

## 验证边界和后续真机验收

浏览器回归证明真实前端在触屏 CSS 条件下的几何与交互；完整 Android CI 另行验证
编译、DEX、资源、既有签名和 APK。两者都不能替代用户手机上的 WebView、系统字体、
键盘和触摸体验。0.33.8 的基线及 0.33.9 的布局修复已由用户确认；0.33.10 新增原生账号页与浏览器往返仍需覆盖安装后确认。

侧栏与文件工具、设置页导航和开关，以及旋转和键盘弹出。出现新的挤压时，先看
