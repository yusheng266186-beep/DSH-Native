## 已完成

### 1. 更新与维护任务互斥

- 新增无 Android 依赖的 `OperationGate`，App 更新与运行包更新同一时间
  只允许一项执行。
- 重复点击或交叉点击时会明确显示当前正在进行的任务，不再启动
  第二个后台线程。
- 发起任务的按钮会进入忙碌态并在成功、失败或提前返回时统一恢复，
  避免同时改写缓存、临时文件或重启 agent。

### 2. 键盘、刘海与横竖屏适配

- `WindowInsets` 路径每次都重新计算左右安全区，不再只在键盘高度
  变化时更新。
- 可见窗口与 `WindowInsets` 两条键盘探测路径独立保存、取较大值；
  任一路径更新底部边距时都不会把横屏刘海的左右边距清零。
- 小于屏幕高度 15% 的可见区变化仍视为系统栏噪声，避免页面轻微跳动。

### 3. 减少动态效果

- 原生层统一读取系统“动画程序时长缩放”。缩放为 0 时，对话框过渡、
  文件列表逐行淡入、顶部进度淡出和开屏呼吸效果都会立即完成或停用。
- 逻辑集中在 `UiPolicy.animationsEnabled`，并覆盖 0、负数、`NaN`和无穷大
  等边界。

### 4. 开屏动画生命周期

- 呼吸动画改为 Activity 持有的 `ObjectAnimator`，开屏隐藏、agent 重启和
  Activity 销毁时均明确启停与复位。
- 修复开屏已不可见后无限动画仍可能持续占用 CPU/GPU 的问题。
- 关闭系统动画时，开屏收起不再额外等待 500 ms。

### 5. 返回确认与顶部进度

- 快速连按返回键时只保留一个确认框，不再通过 `super.onBackPressed()`
  绕过确认并销毁 Activity。确认后仍只是把任务退到后台，agent 继续运行。
- 新页面开始加载时会先取消上一页的进度条淡出，避免旧动画把新的
  加载反馈一起隐藏。

### 6. 深浅主题语义色

- 成功、警示、错误颜色收口到 `DshUi.SUCCESS/WARN/ERROR`，并使用 DSH
  的深色状态令牌：`#22c55e`、`#f59e0b`、`#f25a5a`。
- 命令额度、日志与网络诊断不再各自写死浅色值；日志错误背景也从当前
  主题的错误色派生透明色。

## 真机验收

1. 在已安装的同签名版本上覆盖安装测试 APK；确认系统不要求卸载，会话、
   API 配置、默认工作区与命名项目全部保留。
2. 按阶段四 A 清单确认「App 工具」仍在 DSH 侧边栏内，没有恢复遮挡页面的
   原生悬浮按钮。
3. 进入「更新与维护」，快速连点「检查 App 更新」；只应启动一次，按钮
   显示忙碌态，完成后恢复。
4. 在上一项未完成时点「更新运行包」；应明确提示当前维护任务，不应并行
   下载或重启。反向顺序再验证一次。
5. 在竖屏聚焦 DSH 输入框，键盘弹出后输入区不应被挡；保持键盘弹出并旋转到
   横屏，刘海侧的内容不应被摄像头覆盖，另一侧也不应凭空留白。
6. 连续横竖屏切换三次，分别在键盘显示和隐藏时执行；页面底部、左右安全区
   不得保留上一个方向的边距。
7. 在系统开发者选项将「动画程序时长缩放」设为关闭，重开 App；原生对话框、
   文件列表、顶部进度与开屏不应播放额外过渡，所有功能仍可用。
8. 恢复系统动画缩放，连续重启 agent 三次；开屏呼吸效果应每次重新开始，
   收起后不应在开发者 GPU 指示中持续刷新。
9. 在浅色与深色主题中分别打开命令额度、日志和网络诊断；检查成功绿、
   警示橙和错误红在两种背景下都清晰，日志错误背景不过亮。
10. 任意页面加载完成后立即触发另一次刷新；新的顶部进度条不应被上一次
    的淡出提前隐藏。
11. 快速连按返键三次；只应出现一个退出确认框。选「取消」后 App 保持原页，
    选「退出」后只退到后台，通知栏 agent 状态继续更新。
12. 完成普通对话、工具调用、后台完成通知、文件分享、项目切换、文件编辑和
    诊断导出各一次，确认阶段一至四 A 没有回归。

## 暂未完成与风险

- 键盘与刘海的具体 inset 会受 ROM、手势导航、三键导航与输入法影响；
  纯逻辑已覆盖，但仍必须用目标真机验收。
- 动画开关跟随 Android 的 Animator duration scale。部分 ROM 另外提供“移除动画”
  无障碍开关，如果 ROM 没有把它映射到该缩放值，可能需要后续适配。
- 开屏的系统 Starting Window 仍由 Android 主题决定；本阶段修复的是 Activity 内部
  动画与资源释放，没有做可能影响广泛机型的启动主题迁移。
- 没有提升稳定版、修改稳定/测试更新清单或发布 Release；真机验收后再
  决定是否合并和发版。
