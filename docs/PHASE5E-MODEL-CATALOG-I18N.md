# 阶段五 E：实时模型目录、返回导航与英文完善

本轮是 `0.30.0` 正式版之后的维护修复，正式发布版本为 `0.31.0`。功能分支不手工改正式版清单、签名、包名、targetSdk 或 payload；版本号和稳定清单由通过 CI 后的正式发布工作流统一更新。目标是解决模型中心“检测走上游、选择却读本地预设”的逻辑分裂，并补齐原生设置流程的返回语义、英文说明和项目文档。

## 问题根因

阶段五 C 已经使用只读 `GET /models` 检查密钥和当前模型，但模型选择器仍调用 `ModelConfig.modelsForProvider(...)`：

- Command Code 展示 `settings.yaml` 中的静态能力目录；
- DeepSeek 官方展示 App 内硬编码的两个模型；
- 上游检查结果只更新状态文字，不进入选择器；
- 保存逻辑再次按静态目录校验，因此上游变化无法及时反映。

同时，模型中心虽然有底部“返回”，但文案不说明返回目标，Android 返回手势会由 Dialog 默认取消，无法可靠回到“工具与设置”。其他设置子页也存在同类的“按钮能回父页、手势只关闭当前页”不一致。

## 本轮实现

### 1. 模型列表只以上游响应决定

- Command Code：认证读取 `https://api.commandcode.ai/provider/v1/models`。
- DeepSeek 官方直连：认证读取 `https://api.deepseek.com/models`。
- 每次打开模型选择器都会读取一次；选择器提供“刷新上游列表”。
- 可见列表只包含本次上游响应实际返回的 ID，本地预设不会补入或伪装成在线结果。
- 搜索、数量和日志均以实时响应为准；日志只记录服务商、HTTP 状态与数量。
- 目录请求只执行 `GET`，不发送提示词，不产生模型生成调用。
- 密钥变化立即废弃该服务商的内存目录，旧请求通过 generation/revision 检查不能覆盖新状态。

### 2. 上游可见与本地可用分开表达

上游 `/models` 通常只返回 ID，不提供图片输入、上下文长度和推理等级。DSH 对这些能力有真实校验；把未知 ID 直接标成可用会造成 `UNKNOWN_MODEL`、错误的附件准入或不受支持的 reasoning effort。

因此新增 `LiveModelCatalog` 对齐层：

- 上游响应决定“是否显示”；
- 当前运行环境的配置目录只决定“是否可安全选择”以及图片/推理标签；
- 上游新增但能力未知的模型仍会显示，并明确标注“当前运行环境未声明能力”，但按钮禁用；
- 首次配置和新模型选择必须来自一次成功的实时读取；
- 非首次配置若没有网络，允许原样保存已有服务商/模型，仅修改思考强度或其他设置，避免把用户锁在配置页；
- 不会自动猜测能力，也不会把未知模型静默写进配置。

这既满足“列表从上游直接拉取”，也保持 DSH 的图片、上下文与推理安全边界。

### 3. 返回按钮与系统返回手势

- 模型中心按钮改为“返回工具与设置 / Back to tools & settings”。
- 模型选择器新增“返回模型中心 / Back to model center”。
- `DshUi.onBack(...)` 把 Android 返回键和边缘返回手势接到与可见按钮相同的父级导航。
- 点击卡片外侧不再静默取消设置子页。
- 已接入设置首页、任务中心、会话管理、模型中心、显示与语言、更新与维护、数据与扩展、项目管理、诊断与日志。
- 文件浏览和文本编辑保留各自已有的目录返回、未保存守卫和符号链接保护。
- 从会话管理进入 DSH 官方搜索或归档页面仍是有意离开原生面板，不强行返回设置。

### 4. English 与 README

- 模型目录的加载、失败、数量、兼容状态、保存限制和返回导航均提供中英文文案。
- 设置核心链路中的显示、更新、项目、数据和诊断说明补齐英文。
- 新增完整 `README.en.md`，并在两个 README 顶部提供语言切换。
- 中文 README 重写为当前 `0.30.0` 的真实能力说明，补齐安装、模型中心、项目/文件、更新回滚、隐私、架构、测试和限制。
- Android 桌面快捷方式继续使用现有 `values-en` 资源。
- DSH WebUI 的语言仍由网页设置管理，原生语言设置不会改写网页偏好。

## 逻辑与回归测试

新增 `LiveModelCatalogTest`，覆盖：

- 本地独有模型不得混入上游列表；
- 上游重复与空 ID 的安全处理；
- 已声明能力的模型可选且保留图片/推理元数据；
- 上游新模型可见但不能被误标为受支持；
- 首次引导必须完成实时读取；
- 已有模型在临时离线时可原样保存；
- 切换服务商或选择未知模型不能绕过实时目录校验。

完整回归由 `bash scripts/run_tests.sh` 执行，共 1049 项纯逻辑断言，另含 WebUI 入口、连接恢复、草稿、会话状态和运行包回滚 JavaScript 模拟。PR 的 Android CI 还必须完成 javac、DEX、aapt2、APK 清单、签名和产物上传验证。

## 功能合理性审计

| 功能 | 结论 | 本轮处理 |
|---|---|---|
| 模型目录 | 原选择器与连接检查数据源不一致 | 改为实时上游为唯一可见列表 |
| 未知新模型 | 直接导入会猜测能力并可能制造假可用 | 显示但禁用，说明能力元数据缺失 |
| 已有配置离线编辑 | 强制联网会把用户锁死 | 仅允许原样保留已有路由 |
| 模型中心返回 | 文案不清晰，手势不回父页 | 明确目标并统一按钮/手势 |
| 设置子页返回 | 多个子页默认取消 Dialog | 接入统一父级导航 |
| 点击外侧 | 可能绕过返回逻辑 | 设置流程禁止外侧静默关闭 |
| 会话搜索/归档 | 应继续使用 DSH 官方 UI | 保持现状，不复制私有 RPC |
| 文件编辑返回 | 已有未保存守卫 | 保持现状并纳入回归 |
| 原生/WebUI 语言 | 两套偏好职责不同 | README 明确分别设置 |

## 风险与边界

- 服务商接口、认证要求或响应格式可能变化；异常会显示为密钥拒绝、限流、端点变化、服务失败或无效响应，不回退到伪造的静态在线列表。
- 当前解析最多接受 1 MiB 响应和 500 个唯一模型 ID，界面单次最多绘制前 80 个匹配结果，搜索仍覆盖完整解析结果。
- 上游新增模型若缺少当前运行环境的能力声明，暂时不可选择；这是避免真实会话失败的保护，不是网络目录回退。
- 本轮不增加任意 Base URL、任意请求头或高权限 `JavascriptInterface`。
- 不改 package name、签名、用户数据目录、minSdk 24、targetSdk 28 或现有升级路径。
- 本轮通过完整 Android CI 后合并，并由正式发布工作流提升到 `0.31.0` stable；不得手工创建 Release 或提前改写 `latest.json`。

## 真机验收

1. 从 `0.30.0` 正式版覆盖安装 CI APK，确认会话、密钥、项目、任务历史和文件仍在。
2. 切换原生语言为 English，重开工具与设置，检查首页、Model center、Display & language、Updates、Projects 和 Diagnostics 文案。
3. 进入模型中心，分别选择 Command Code 和 DeepSeek direct；未填密钥时点击 Choose model，应提示先填当前服务商密钥。
4. 使用有效密钥打开选择器，确认出现加载状态、真实上游数量、搜索框和刷新按钮；列表不得包含上游没有返回的本地预设。
5. 用错误密钥确认显示拒绝；飞行模式下确认显示连接失败且不会回退静态列表；日志不得出现密钥或响应正文。
6. 若上游返回当前运行环境未知的模型，确认该项可见、原因明确且不可点击；已支持模型可选择并保存。
7. 改变密钥后重新打开选择器，确认不会复用旧密钥对应的目录。
8. 通过底部“返回模型中心”和系统边缘返回手势分别返回；再从模型中心返回工具与设置，路径应一致。
9. 依次进入任务、会话、显示、更新、数据、项目和诊断子页，用返回按钮及系统手势验证都回到正确父页。
10. 在深色、横屏、系统大字体与动画关闭状态下重复模型选择；按钮不得被压扁，禁用态与加载态应可辨认。
11. 修改全局模型及一个项目覆盖，新建会话确认生效；已有会话不得被静默改写。
12. 检查通知栏、长按顶部和桌面快捷方式仍能打开 App 工具，侧边栏收起时的 DSH 齿轮仍只打开 WebUI 设置。
