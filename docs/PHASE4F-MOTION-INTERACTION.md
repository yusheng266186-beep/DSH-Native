## 归档状态与后续变更

本阶段对应实现已进入主分支。以下验收步骤、测试数量和发布限制保留当时版本语境；当前完成范围与未验证项目统一见 [STATUS](STATUS.md)。

## 原始阶段记录

阶段四 F 承接已经完成真机验收的阶段四 E，只调整原生工具界面的动效与交互反馈，
不改动任务状态判定、通知语义、侧边栏设置归属、工作区、会话或签名链路。
本阶段的目标不是增加装饰，而是让“打开了什么、按下是否生效、当前选择是什么、
正在前进还是返回”在手机上能够直接感知。

## 已完成

### 1. 面板内容分层进入

- 原生面板进入由 180 ms / 10 dp 调整为 240 ms / 18 dp，退出调整为
  160 ms / 10 dp，仍只使用透明度和位移，不触发布局重排。
- 每个面板首次挂载时，标题、说明、控件和底部操作区按 24 ms 间隔依次上移淡入。
- 延迟最多累计 6 档；超长或复杂面板按整体处理，避免长表单逐项慢放。
- 动画直接作用于合成属性，横竖屏、系统大字体和滚动内容不会因此重新测量。

### 2. 设置页前进与返回有方向感

- 从“工具与设置”进入五个分类时，当前卡片先向左短距离退出；返回上一级时向右退出。
- 110 ms 换页完成后再创建下一页，避免两个对话框同时闪现。
- 换页期间使用一次性门闩，快速连点不会重复打开多个设置面板。
- “数据与扩展 → 管理项目”不再把旧页面留在后台并在返回时再叠一层新页面。

### 3. 按钮触摸和任务结果更明确

- 所有 `DshUi` 按钮在原有按下色基础上增加圆角范围内的水波纹。
- 按压缩放由不易察觉的 0.98 调整为 0.96；按下 85 ms、回弹 145 ms，
  不改变控件占位，不会挤压相邻文字或按钮。
- 忙碌、完成结果和恢复默认文案都会短促淡入，网络检测、更新、导出、保存等
  长操作不再只靠一行文字瞬间跳变表达状态。
- 禁用态和重复提交保护保持不变。

### 4. 离散选项有视觉、触觉和无障碍反馈

- 语言、显示缩放和更新通道切换后，整组选项会在 180 ms 内淡入复位。
- 选择动作使用系统触觉反馈；系统关闭触觉时不会强制振动。
- 选项按钮现在带有“已选中 / 未选中”的双语无障碍描述，TalkBack 不再只能朗读标签。
- 文件浏览器中已有的目录、隐藏文件和排序选中态也会在真正改变时淡入确认。

### 5. 尊重减弱动画与性能边界

- “动画程序时长缩放”为 0 时，不安装水波纹、按压缩放、分层进入、选项过渡或换页动效；
  功能和按下色仍可正常使用。
- 没有引入 `LayoutTransition`、弹性动画、无限装饰动画或额外 WebView 桥接。
- 没有改写 DSH WebUI 的全局动画，避免上游页面升级后出现样式冲突。

### 6. 可辨识的验收版本

- 验收包版本为 `versionName 0.26.2`、`versionCode 2602`。
- 包名、`minSdkVersion`、`targetSdkVersion = 28` 和签名策略保持不变，可覆盖安装验证。
- 该版本号只用于本阶段测试包；未修改稳定版/测试版更新清单，未发布 Release。

## 自动验证

- 本地 `bash scripts/run_tests.sh`：26 个纯 Java 测试程序、787 项断言全部通过；
  3 个真实 JavaScript 引擎模拟共 35 项断言全部通过。
- `scripts/run_tests.sh` 覆盖动效时长、按压深度、分层延迟边界、系统动画关闭回退、
  动画 XML、圆角水波纹、选项无障碍状态、设置前进/返回接线和忙碌结果反馈。
- 同一套测试同时在仓库布局与 CI 的 `bootstrap/src` 布局下运行，避免测试只在本地路径通过。
- WebUI 工具入口、会话探针、任务状态、操作互斥、键盘安全区和阶段四 B/C/E 回归继续保留。
- 完整 Android `javac`、DEX、aapt2、签名、清单和 APK 上传以本阶段 PR 的 GitHub Actions
  结果及交付说明为准。

## 真机验收

1. 在 0.26.1 或同签名正式包上覆盖安装，进入“更新与维护”，确认当前 App 版本为 0.26.2。
2. 连续打开“工具与设置”、日志、文件、网络诊断等原生面板；标题和内容应有清晰但不拖沓的
   分层上移淡入，退出无闪白或布局跳动。
3. 从设置主页依次进入“账号与模型”“显示与语言”“更新与维护”，再点返回；
   前进应向左、返回应向右，快速连点不得叠出两个面板。
4. 短按主按钮和次按钮；应同时看到按下色、水波纹和约 4% 的下沉感，松手立即平滑复位，
   按钮高度和周围布局不应变化。
5. 切换语言、100% / 115% / 130% / 150% 缩放及稳定版/测试版通道；
   应收到一次轻触反馈，选项组短促淡入，且只能有一个选中项。
6. 运行一次网络检测或更新检查；按钮的忙碌、结果和默认文案应分别有可见过渡，
   连点仍不能重复提交。
7. 开启 TalkBack 聚焦各个选择按钮，确认能朗读标签及“已选中 / 未选中”。
8. 在开发者选项中把“动画程序时长缩放”设为关闭，重新打开 App；所有装饰动效应立即消失，
   但按钮按下色、设置换页和各项功能仍正常。
9. 在浅色/深色、中文/英文、横/竖屏和系统最大字体下重复第 2 至 5 步，确认没有裁切、
   抖动、压扁或点击区域偏移。
10. 再次确认阶段四 E 的两项回归：无任务时通知不显示“状态未知”；侧栏收起时点击齿轮仍打开
    DSH 自己的设置，而不是 App 工具。

## 未完成与风险

- 动效流畅度、不同刷新率屏幕、水波纹观感、ROM 触觉强度和 TalkBack 实际播报仍需目标真机验收；
  JVM 与 CI 无法替代这些感知项。
- 本阶段没有重做 DSH WebUI 自身的会话动画；网页区域继续由上游前端负责，降低补丁失效风险。
- 没有合并 `main`、发布稳定版、修改更新清单、迁移签名密钥或改变现有用户升级路径。
