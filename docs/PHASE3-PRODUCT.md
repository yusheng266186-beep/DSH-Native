## 原始阶段记录

本阶段把前两阶段的稳定性和首次体验继续推进到日常使用：让界面适配手机，
让不同任务有独立项目空间，让系统分享真正形成任务，并把插件与预发布风险显式交给用户选择。

本阶段保持 `targetSdkVersion = 28`，不迁移签名密钥，不移动或删除既有工作区文件。
首个交付使用测试通道 GitHub Prerelease，真机验收通过后再决定是否提升为稳定版。

> 阶段四 A 修订：真机反馈确认右上角悬浮入口仍可能覆盖网页控件，已改为 DSH 侧边栏内的
> 「App 工具」入口。下方涉及右上角入口的历史验收项由 `PHASE4A-WEBUI-TOOLS.md` 取代。

## 已完成

- WebView 不再固定桌面宽度：窄屏保留可读的 480 CSS px，横屏和平板使用实际宽度，
  并为对话框、表单、触控目标和长代码块注入幂等的响应式 CSS。
- 增加命名项目：默认工作区原样保留，新项目位于 `workspace/projects/<项目名>`；
  项目名有长度、路径和控制字符校验，切换前会保护正在运行或等待批准的任务。
- 系统分享支持单文件、多文件和文本。内容保存后会列出结果并询问是否创建任务；
  DSH 页面未就绪时暂存任务，找不到发送按钮时保留已填内容供用户确认。
- 插件默认不再自动启用。启用前展示能力与风险，用户授权绑定插件名称、版本和包内容指纹；
  插件更新后旧授权自动失效并重新询问。
- 增加稳定版/测试版更新通道。稳定版只读取 `latest.json`；测试版同时读取
  `latest-test.json` 与稳定清单并取更高版本。
- 发布流水线支持 `test`：创建 `v<版本>-test` Prerelease，只更新测试清单，
  不覆盖 README 和稳定下载入口；两种通道都保留签名一致性与下载可用性校验。

## 自动验证

- 21 个纯 Java 测试程序，共 650 项断言；本阶段新增 57 项，覆盖响应式补丁、
  项目目录约束、分享任务生成与转义、插件授权指纹和发布通道规则。
- Java 全量语法与跨类引用、资源 XML、纯逻辑层 Android 依赖、系统 `AlertDialog`、
  emoji、Shell/Python 语法、发布元数据和 git 空白检查。
- 完整 Android `javac`、DEX、aapt2、APK 签名与发布下载链路由 GitHub Actions 验证。

## 安全与兼容边界

- 插件授权是“启用前确认 + 运行时阻止未授权插件”，不是 Android 操作系统级沙箱。
  插件仍与 DSH 同进程、同权限运行，第三方插件必须来自可信来源。
- 旧用户已保存的插件选择不会静默运行；首次进入新版本后需按当前插件版本重新授权。
- 默认工作区继续使用原目录；命名项目只是新增子目录，不做数据迁移，也不提供删除功能。
- 分享内容总是先保存。自动创建任务依赖 DSH 网页的输入框与发送按钮结构；若上游结构变化，
  App 会给出提示并保留文件，最坏情况退化为用户手动提交，不会丢数据。
- 测试版与稳定版使用同一包名和签名，可以覆盖安装；测试版尚未完成真机验收，
  不会推送给仅选择稳定通道的用户。

## 真机验收步骤

1. **覆盖安装**：在现有稳定版上安装测试 APK，确认系统允许覆盖，账号、会话、默认工作区不丢失。
2. **手机布局**：在竖屏、横屏、系统大字体下打开对话、设置和长代码块；确认无横向截断，
   对话框可滚动，按钮易于点击，且阶段四 A 的侧边栏工具入口不覆盖网页内容。
3. **项目兼容**：确认旧文件仍在“默认工作区”；新建两个项目，分别写入同名文件并切换，
   验证互不覆盖。任务运行时切换应出现中断确认。
4. **分享闭环**：从文件管理器一次分享多个文件，再从浏览器分享一段文本；确认都进入当前项目，
   取消“创建任务”不删文件，确认后任务被发送或至少正确预填。
5. **冷启动分享**：强制停止 App 后从其他应用分享，确认环境完成启动后任务自动继续，而不是丢失。
6. **插件授权**：首次启用内置插件应显示能力披露；取消后不生效，确认后重启生效。
   更新或重新安装不同版本的第三方插件后，应要求重新授权。
7. **更新通道**：稳定通道不应看到本次测试版；切到测试通道后检查更新，应识别测试清单。
   切回稳定通道立即生效且不触发重启。
8. **基础回归**：完成一次普通对话、工具调用、后台完成通知、文件编辑与诊断导出；
   查看日志中是否出现启动失败、未授权插件跳过或分享提交错误。

## 暂未完成

- 没有把第三方插件放进独立 Android 进程或容器；这需要重新设计 DSH 插件宿主，不能以 UI 授权代替。
- 没有提供项目重命名、删除、导入或导出；删除前还需定义会话引用与误删恢复策略。
- 没有承诺测试版为稳定版；只有上述真机验收完成后才应更新稳定通道。
