目标日期从 2026-10-27 开始，基线为 stable 0.40.2。按用户要求顺序完成六项，最后统一验收并发布 1.0.0；中间提交用于审查，不提前宣称正式版完成。

## 完成标准与边界

- 每项先检查生产消费路径，记录实际问题、修复、回归命令和结果，再进入下一项。没有复现的历史报告保持未确认，不写成已修复。
- 自动化使用真实固定内核、实际网页组件、生产 Java/JS 和必要的 Android API 替身；不做真机或模拟器验证。手机体验由用户安装验收，自动检查不等于 ROM、录音、外部应用或服务商全模型实测。
- 不删用户历史、项目、附件或凭据，不自动重发聊天，不更换包名和签名，不偷偷降低模型强度。未知状态保留为未知。
- 最终保留故障定位和恢复入口；错误说明给出可执行的下一步，不记录密钥、对话正文或语音内容。

## 综合验收与发布

六项结束后依次执行：

1. 重新审查全部变更及跨任务影响，完成完整 JVM/脚本回归、Java 静态检查和 Android API 编译。
2. 消费固定 payload 的实际内核/工具/模型/网页/会话保存链；执行全部设置和手机布局自动回归。新增失败必须修复后重跑受影响检查。
3. 完整 Android CI 使用最终候选提交，核对 APK 包名、递增版本、SDK、原证书及资源/负载；只有生成文档清单的变动可复用完全相同代码的已验证产物。
4. 合并 main，经 release.yml / release.sh 发布；先上传 APK，再验证直连/镜像及实际字节，最后生成并提交更新清单。
5. 核对公开 stable 版本、资产大小/SHA、签名、清单和 README 下载一致。发布说明分别列出自动验收结果与留给用户手机验收的项目。

## 执行记录

### 任务 1

- 复现：stopAndWait 在进程锁内等待时，状态读取的 250ms 截止检查失败。等待移出锁后通过，并验证并发替换不能被旧停机误判为空闲或清除。
- 修复：旧进程输出不能发布新实例地址；stdout 关闭不再当作进程退出。自动刷新要求前台、未销毁及新的任务空闲证据，返回前台再恢复计时。
- 验证：ProcessSupervisorTest 24 项、ConnectionRecoveryTest 17 项通过；真实固定 Connection 服务 12 项，含 10 秒退避提前恢复、20 次生命周期事件、清理后无重连；完整 run_tests.sh 与 Android API 28 编译通过。
- 边界：这是已证实的线程阻塞缺口，不能证明历史每次卡死均由它导致。Android 后台回收/ROM 行为留给用户安装确认；未自动重发任何提示词。

### 任务 2

- 配置恢复改为先完整准备，再落盘带摘要的原配置撤销记录，最后替换文件；失败立即还原，进程中断由启动流程在复用内核之前恢复。新增/原有配置分别处理；全部路径先校验，不允许内部符号链接别名。记录只在私有 .dsh 中，正常完成即删除。
- 运行包更新/恢复在修改前保存持久中断标志。启动先处理旧快照恢复；首次安装中断则重新核对并解压全部片。恢复本身再次中断仍保留标志，失败不凭关键文件存在继续启动混合版本。替换前等待旧内核真实退出。
- 验证：ConfigBackupTest 64 项（含新增 14 项故障边界）、PayloadRollbackTest 31 项；check_payload_recovery.py 28 项执行生产 Java 恢复方法和实际 snapshot.js/unpack.js，覆盖强制子进程退出、后续目标存储失败、损坏快照与重试，用户数据 canary 保留。完整 run_tests.sh、Android API 28 编译与静态闸门通过。
- 边界：存储故障采用可控写入失败，未填满用户磁盘。验证进程中断，不承诺突然断电时所有文件系统的持久顺序；没有真机覆盖安装/恢复实测。静态解析器未安装，语法与类型由实际 javac 验证。

### 任务 3

- 改前在真实模型页复现导入按钮 26px 内容区承载 29px 字高，放大文字被裁切；模型展开行和上游打开配置文件按钮同样存在固定高度约束。补充语义 data 锚点，只修相应动作行，图标保留原尺寸。平板导航标签完整换行并增加可用宽度，手机保留原 Menu。
- 保持 480 CSS px 下限及原主题令牌；LayoutProbe 新增 text-clipped 标记，仍不记录页面文字。旧布局回归一度误用本机遗留触屏脚本，换成当前 Java 实际生成脚本后通过；这不是产品新增故障。
- 验证：6 组深浅色/语言/短屏/平板/放大文字的实际设置和 Java 控制器消费共 786 项；13 组旧前端触屏场景 1165 项，覆盖附件、文件预览/分享、语音、插件、自动化、全部设置分类、硬件返回和状态边界。完整脚本、布局探针隐私检查和 Android API 28 编译通过。截图保留在隔离证据目录，检查了模型及导航的实际渲染。
- 边界：放大文字用 CSS 字号压力检查，短屏近似键盘可用区域；不冒充 Android textZoom、系统键盘或手机触摸实测。
