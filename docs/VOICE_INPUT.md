0.35.0 为 DSH 语音输入插件接入 Android 系统识别，并修复通知栏只依赖网页探针、后台或 WebSocket 请求时读不到任务的问题。

## 使用语音输入

1. 覆盖安装新版，在更新与维护中重启内核，让插件加载新的适配模块。
2. 在 DSH 插件页启用“语音输入”，进入插件详情，点击“检测语音服务”。
3. 返回会话，点击输入栏麦克风；首次使用系统识别服务时按提示允许麦克风。
4. 说话后等待识别，或点击“结束并识别”。结果只插入草稿，由用户确认发送。

Android 31 以上支持端侧识别时优先使用端侧；端侧语言不支持或模型未就绪时回退系统默认识别服务。没有可连接的识别服务、但系统提供语音识别窗口时，改用系统窗口完成输入。没有服务或窗口时显示明确提示，可在系统中安装/启用支持的识别服务，也可使用输入法语音。

0.35.1 起会核对系统已选择且启用的默认识别服务，不把“系统注册过服务”当作默认引擎可用。端侧和默认识别器的错误 5/11/12/13、创建或启动异常会按可用路径回退，最后尝试系统语音窗口，每条路径最多一次。系统窗口由对应应用管理麦克风权限；不会因用户拒绝 App 麦克风权限而自动打开其他录音入口。

“结束并识别”只在系统报告准备好后出现，结果处理中不重复停止。启动阶段 12 秒无回调进入兼容回退；取消、离开前台或切换会话后不再执行排队的回退。识别结果仍只写草稿。

长错误与保留的转写在有高度上限的正文区域滚动；重试、系统设置、插入和取消按钮独立排列，短横屏不会因为错误说明变长而失去操作入口。

中文界面请求 `zh-CN`，英文界面请求 `en-US`。系统服务决定语言、离线模型及是否联网；不保证所有国内 ROM 都预装兼容的 Android 识别接口。普通浏览器仍使用原插件组件。

## 出错时如何定位

| 现象 | 检查与操作 |
|---|---|
| 输入栏没有麦克风 | 确认语音插件已启用，安装后已重启内核；插件详情应显示 Android 系统语音输入 |
| 提示没有系统语音服务 | 在详情点击“系统语音设置”，检查是否启用可用识别引擎；键盘的私有语音功能不一定提供 Android 系统识别接口 |
| 点击麦克风立即错误 5 | 升级 0.35.1 并重启内核，观察是否转入系统语音窗口；仍失败时点击错误面板的“系统语音设置”，选择/启用识别引擎并导出诊断 |
| 提示麦克风未授权 | 在系统 App 权限允许麦克风，并检查手机的麦克风隐私开关 |
| 麦克风打不开或服务忙 | 关闭其他录音应用，取消当前识别后重试；不要同时启动两次 |
| 网络、超时或语言错误 | 核对系统识别引擎的网络/语言/离线模型；详情可重新检测服务 |
| 识别后没有直接进入草稿 | 若录音时草稿变化或输入框被锁定，文字保留在面板，点击“插入到当前光标” |
| 切换会话后无结果 | 切换、取消和销毁会终止旧请求，旧回调不能写入其他会话 |

仍有问题时，从 App 日志/诊断导出 ZIP，并说明操作时间、界面错误码、系统语音引擎名称、是否弹出权限或系统识别窗口。`Voice input` 包含阶段、错误码、模式、默认组件、异常类和有界尝试链；运行日志记录失败阶段，不记录录音或识别文本。无需先清数据或卸载。

错误 5 是 Android 的通用客户端错误。Android 源码中，未选择默认服务、服务绑定/管理器不可用都可能产生该错误；不能仅凭这个数字判断为网络或麦克风问题。参见 [SpeechRecognizer API](https://developer.android.com/reference/android/speech/SpeechRecognizer#ERROR_CLIENT) 和 [Android 默认服务解析源码](https://android.googlesource.com/platform/frameworks/base/+/676d687dc7ab4ff088188af9dbb7d9ca488b0303/core/java/android/speech/SpeechRecognizer.java)。

识别请求限定前台本机页面；不开放任意网页的麦克风桥。系统服务录音在离开前台时取消，系统权限窗口和外部识别窗口保留必要的返回流程；超时、取消和销毁释放识别器。

## 通知栏状态

原生 `HarnessService` 每约 3 秒向同一认证本机内核调用 `session/list`，完整校验返回值，任意会话 `running=true` 即为运行中。读取失败、未启动或过期显示同步中/未知，不判作空闲，不触发自动重启。页面只补充等待批准及连接信息。

常驻通知不会因重复的状态推送重置为初始占位文案。运行中的限时 CPU 唤醒锁随状态续期，空闲或停止释放；查询失败不续期。后台确定完成且已观察任务持续至少 10 秒时通知，前台不重复打扰。系统和 ROM 仍可限制后台运行，建议允许通知及后台运行。

状态异常时导出诊断，查看 `Native task source` 与日志的状态变化；附上任务是否仍在运行、App 是否在前台、是否锁屏的信息。连接丢失与任务结束是独立事实。

## 已有验证

真实 payload-v13 内核通过生产 Java 认证通道验证空闲、运行、完成和非法响应；语音使用真实插件组件及合成识别事件验证插入、取消、超时、权限错误、草稿变化与中英文。触屏布局覆盖窄屏、大字体、低高度、横屏和平板。

`check_native_voice.py` 直接编译执行生产 `NativeVoiceController`，仅替换 Android API 边界，覆盖默认缺失、立即错误 5、端侧/默认/窗口有界回退、初始化异常、取消与晚回调、启动超时、停止时序及授权返回。旧 0.35.0 控制器在默认缺失场景下可复现失败。该测试无设备、录音或真实 ASR，不将成功的合成转写扩大为系统识别通过。

Android 编译与自动回归不等于系统麦克风和语音引擎验收。本轮按用户约定不做真机验证，由用户在小米 17 Ultra 上下载安装调试。

Android 接口依据：[SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer)。
