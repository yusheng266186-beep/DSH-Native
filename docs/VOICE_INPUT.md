## 使用语音输入

1. 覆盖安装新版，在更新与维护中重启内核，让插件加载新的适配模块。
2. 在 DSH 插件页启用“语音输入”，进入插件详情，点击“检测语音服务”。
3. 返回会话，点击输入栏麦克风；首次使用页面内识别时按提示允许麦克风。
4. 面板跟随 DSH 深浅主题，显示聆听状态、计时和音量。服务提供临时结果时显示预览；说话后等待最终结果，或点击“结束并识别”。最终结果只插入草稿，由用户确认发送。

自动模式在 Android 31 以上支持时优先端侧识别，再使用可用的实际默认识别服务。未配置默认服务时，尝试绑定与系统语音窗口同一提供方的公开 RecognitionService。不会自动试用其他无关提供方。插件详情的“识别引擎”可以选择实际检测到的公开服务；显式选择优先于自动端侧，失效的已选服务恢复自动选择。

页面内路径只绑定已声明 RecognitionService、启用且导出的组件。端侧失败可有界改用所选页面内服务，服务失败会留在输入面板，不自动打开系统框。没有公开可用服务或服务启动失败时，可主动点击“使用系统语音”保留 0.35.1 已可用的窗口路径；该窗口由识别服务提供方绘制，DSH 不能隐藏或换肤。系统麦克风授权/隐私提示仍由 Android 管理。

系统权限选择“仅在使用此应用时允许”即可。App 不用申请持续后台录音权限。收到授权回调后，重新等待 Activity 前台、WebView 可见且窗口焦点连续稳定 250ms；首次请求权限前与已授权后的每次启动也执行同一检查，真正调用识别器前复核实际权限。等待上限 4 秒，面板显示“正在等待应用窗口就绪”，取消立即终止。超时单独提示返回 DSH，不混为麦克风被拒绝。无需先调用系统麦克风“预热”。

识别器尚未 ready 时，服务回调错误 5 或 9、实际麦克风授权仍有效且 App 在前台，可销毁旧实例后等待前台就绪并最多重试一次。实际拒绝/撤销权限、创建异常、开始录音后的错误不重试；离开 App 或取消后不会在返回时自动录音。系统权限窗口返回保留短暂等待，但离开后最多 4 秒即终止，不留下后台请求。

“结束并识别”只在系统报告准备好后出现，结果处理中不重复停止。启动阶段 12 秒无回调进入兼容回退；取消、离开前台或切换会话后不再执行排队的回退。识别结果仍只写草稿。

音量条读取真实 RMS，服务不提供音量时保持静止，不伪造录音活动。临时文字只预览，取消或跨会话回调不写入草稿。长错误、临时文字与保留转写在有高度上限的正文区域滚动；重试、手动窗口、系统设置、插入和取消动作独立排列，短横屏压缩装饰标题，避免失去操作入口。减少动态效果偏好会关闭音量条过渡。

中文界面请求 `zh-CN`，英文界面请求 `en-US`。系统服务决定语言、离线模型及是否联网；不保证所有国内 ROM 都预装兼容的 Android 识别接口。普通浏览器仍使用原插件组件。

## 出错时如何定位

| 现象 | 检查与操作 |
|---|---|
| 输入栏没有麦克风 | 确认语音插件已启用，安装后已重启内核；插件详情应显示 DSH 内语音输入 |
| 提示没有系统语音服务 | 在详情点击“系统语音设置”，检查是否启用可用识别引擎；键盘的私有语音功能不一定提供 Android 系统识别接口 |
| 页面内立即错误 5 | 在插件详情检测/选择公开引擎，或点击“使用系统语音”；仍失败时导出诊断。自动窗口回退只属于旧 0.35.1 行为 |
| 只能用系统窗口 | 表示手机未提供可直接使用的公开识别服务，或绑定失败；DSH 不能把其他 App 的识别窗口重新绘制在网页内，可选择兼容引擎或使用保留的窗口路径 |
| 应用窗口尚未就绪（1002） | 关闭系统弹窗并返回 DSH 后重试；授权与窗口焦点返回顺序可能不同，不必改为后台录音权限 |
| 提示麦克风未授权 | 在系统 App 权限允许麦克风，并检查手机的麦克风隐私开关 |
| 麦克风打不开或服务忙 | 关闭其他录音应用，取消当前识别后重试；不要同时启动两次 |
| 网络、超时或语言错误 | 核对系统识别引擎的网络/语言/离线模型；详情可重新检测服务 |
| 识别后没有直接进入草稿 | 若录音时草稿变化或输入框被锁定，文字保留在面板，点击“插入到当前光标” |
| 切换会话后无结果 | 切换、取消和销毁会终止旧请求，旧回调不能写入其他会话 |

仍有问题时，从 App 日志/诊断导出 ZIP，并说明操作时间、界面错误码、系统语音引擎名称、是否弹出权限或系统识别窗口。`Voice input` 包含阶段、错误码、模式、默认组件、异常类、有界尝试链、实际权限、前台就绪与是否进行过启动重试；运行日志记录失败阶段，不记录录音或识别文本。无需先清数据或卸载。

错误 5 是 Android 的通用客户端错误。Android 源码中，未选择默认服务、服务绑定/管理器不可用都可能产生该错误；不能仅凭这个数字判断为网络或麦克风问题。参见 [SpeechRecognizer API](https://developer.android.com/reference/android/speech/SpeechRecognizer#ERROR_CLIENT) 和 [Android 默认服务解析源码](https://android.googlesource.com/platform/frameworks/base/+/676d687dc7ab4ff088188af9dbb7d9ca488b0303/core/java/android/speech/SpeechRecognizer.java)。

识别请求限定前台本机页面；不开放任意网页的麦克风桥。系统服务录音在离开前台时取消，系统权限窗口和外部识别窗口保留必要的返回流程；超时、取消和销毁释放识别器。

## 通知栏状态

原生 `HarnessService` 每约 3 秒向同一认证本机内核调用 `session/list`，完整校验返回值，任意会话 `running=true` 即为运行中。读取失败、未启动或过期显示同步中/未知，不判作空闲，不触发自动重启。页面只补充等待批准及连接信息。

常驻通知不会因重复的状态推送重置为初始占位文案。运行中的限时 CPU 唤醒锁随状态续期，空闲或停止释放；查询失败不续期。后台确定完成且已观察任务持续至少 10 秒时通知，前台不重复打扰。系统和 ROM 仍可限制后台运行，建议允许通知及后台运行。

状态异常时导出诊断，查看 `Native task source` 与日志的状态变化；附上任务是否仍在运行、App 是否在前台、是否锁屏的信息。连接丢失与任务结束是独立事实。

## 已有验证

真实 payload-v13 内核通过生产 Java 认证通道验证空闲、运行、完成和非法响应；语音使用真实插件组件及合成识别事件验证插入、取消、超时、权限错误、草稿变化与中英文。触屏布局覆盖窄屏、大字体、低高度、横屏和平板。

`check_native_voice.py` 直接编译执行生产 `NativeVoiceController`，仅替换 Android API 边界。当前覆盖无默认时显式绑定同提供方、已选引擎、非公开服务拒绝、真实音量事件/节流、临时文字预览、默认无弹框、显式系统窗口、初始化异常、取消/晚回调、超时、授权先于 onResume/窗口焦点返回、焦点抖动、真实权限撤销、前台超时与有界启动重试。该测试无设备、录音或真实 ASR，不将合成转写扩大为系统识别通过。

Android 编译与自动回归不等于系统麦克风和语音引擎验收。本轮按用户约定不做真机验证，由用户在小米 17 Ultra 上下载安装调试。
