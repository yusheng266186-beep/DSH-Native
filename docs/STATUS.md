## 0.40.2 的缓存统计与小鲸鱼动画

- 用户报告 CodeBuddy 接入在 DSH 面板聊几十轮仍不到 50%。通过内置官方 SDK 连接本机合成服务复现：服务返回总输入 1000、缓存读取 900，CLI 的 message/result usage 仍给出 input_tokens=1000，而 per-model usage 给出未缓存输入 100。旧适配把 1000 当作未缓存输入，导致 900/(1000+900)=47.4%，实际响应应表示 90%。
- 普通结果优先消费 SDK 已归一化的 per-model 数值；流式/工具返回按当前固定 CLI 默认通道的总输入减去缓存读写，向 DSH 提供不重叠的桶及精确总量。缺失缓存字段保留未知；修正实际 TokenMeter 的上下文压力，避免把缓存重复加到占用。新请求使用新口径，已有历史统计原值保留，不回写用户会话。
- 加载三点改为品牌鲸鱼矢量轻游，配细水波和小气泡，深浅色用品牌令牌。鲸鱼保持不透明，不再闪烁或缩放呼吸。保留真实握手与首帧、当前周期末交接、更新循环、减少动态效果及后台暂停。
- 42 项 SDK 协议/运行包检查、7 项实际官方 SDK/本机合成服务检查、54 项真实内核投影/压力/网页百分比检查和 20 项原生 View 边界通过。50 轮回放在实际 UI 格式化器得到 90%，上下文压力为真实 1000；合成数据不证明用户真实服务商当前命中率。Android 编译、完整 CI 与既有功能回归见本轮记录；仍不做真机验证。

## 0.37.2 的原生动作可靠性

- 复现准备文件期间切换项目后仍打开旧分享的问题；文件请求绑定最初的 Activity 与工作区，真正打开前重新复核前台、窗口和项目。不匹配明确 CONTEXT_CHANGED，仅删除本次未交付的副本，保留原文件和既有分享缓存。
- 窗口处理器拒绝、UI 超时、调用取消和服务停止均取消并移除未开始的 FutureTask；已经中断的调用不再排队。截图在授权窗口创建期间取消也会撤销该请求，避免遗留等待者。
- ActivityNotFoundException / SecurityException 映射到无处理 App / 系统拒绝；缺失通知渠道明确报错，失败通知不消耗成功通知限流。文件暂存失败给出独立错误，不输出系统异常正文。
- JS 客户端保留 400 参数错误与 403 认证错误，区分真实响应期限与连接失败；有副作用的调用不自动重试。实际 ToolRuntime / Java HTTP / CLI 消费回归和不应答本机 peer 检查这些路径。
- 本轮新增 47 项实际 NativeBridge 可靠性边界检查，原 42 项动作/协调器和 59 项截图服务回归保留；真实内核工具链/HTTP/CLI/期限共 18 项通过。Android API 为替身，没有真机操作；完整 Android、真实内核与旧布局检查以本轮 CI/发布记录为准。

0.33.10 的真实内核账号回归通过 45 项检查（本机合成平台、生产 Java RPC）；触屏前端通过六组共 294 项检查。用户随后反馈真机登录成功，但首次任务保存失败；这不证明账号任务已完整可用，也不扩大 0.33.9 的布局验收范围。
