## 0.33.11 的 Android 保存与上游账号界面

- 用户反馈 0.33.10 可登录账号，但首次任务在压缩会话 link() 时失败；根因是首次保存未打补丁且缺少 EACCES 分支。
- SessionPersistencePatch 在启动时修复现有运行包的首次保存及迁移，使用共用排他复制辅助函数并同步文件；保护同名历史与真实写错误。
- 删除独立原生账号面板，App 工具及模型中心直接打开 DSH 原始账号与余额页面，保留 profile、充值/赠金余额、用量、充值和退出。
- 只适配 Web 授权、前台浏览器、签出设置入口和导航；不制造 Desktop 桥，保留上游状态流和余额失败显示。
- 修复自动模型引导覆盖设置；App 工具通过实际 settings.launcher 锚点挂载，避免挤压账号菜单。
- 账号及凭据正文不进网页诊断；旧进程版本不符时要求显式重启，不把写回模块说成已被进程采用。

本轮回归通过真实保存 EACCES 的 39 项检查、上游账号组件与合成平台的 85 项检查，以及六组触屏布局的 306 项检查。
用户真机上的新版首次任务和账号设置体验尚待确认；不将合成服务响应当作真实额度或付费请求验证。

## 0.33.10 的配置与账号修复

- 模型列表更新移入 App 工具的模型中心，三种服务商纵向显示；账号路线不显示 API Key 输入。
- 使用内核真实账号 RPC 与浏览器授权，不伪造 Desktop 桥。API Key 修改通过内核凭据接口，避免旧全文覆盖账号 grant。
- legacy 文件导入后读取公开 `settings/describe`，修复原生模型列表与项目覆盖忽略当前 profile 的问题。
- 加密备份包含 active Web profile 与导入快照，恢复先检查全部目标，并拒绝越界符号链接。
- 原生配置/网络工作进入有界后台队列，重启/销毁取消请求；项目切换将未知状态纳入中断提示。
- 启动 URL 与授权参数脱敏，WebView 本机地址使用准确的 host/port 判断。
- 内核端口/令牌变化时关闭旧原生接口；首次引导不再显示过时的下载与空间估算，实际预检按清单计算。
- 需要导入 legacy 配置时核对内核实际模型配置，避免服务地址已出现但模型目录尚未就绪的启动竞争；系统日志也脱敏。

0.33.10 的真实内核账号回归通过 45 项检查（本机合成平台、生产 Java RPC）；触屏前端通过六组共 294 项检查。用户随后反馈真机登录成功，但首次任务保存失败；这不证明账号任务已完整可用，也不扩大 0.33.9 的布局验收范围。
