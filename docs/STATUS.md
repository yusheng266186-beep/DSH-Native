## 0.39.0 的 CodeBuddy CLI 与设置结构

- APK 内置官方 SDK 0.3.291 / CLI 2.176.0。现有托管 CodeBuddy 路由交给官方 CLI 代理，Key 仍从 DSH 凭据解析。移除旧的额外产品/IDE 请求头；CLI 使用自身代理行为，不以 DSH 组合人格替换 CLI 人格。工具通过公共 SDK MCP 接口交回 DSH，CLI 内置工具、额外设置源及会话持久化关闭。
- beichen 的简单 Bearer + stream 请求可用，但完整 DSH 直连请求及以 DSH 人格运行的 SDK 请求均遭 11128。官方标准代理模式实际完成 DSH 写文件、读回及回复存储；普通 Node 与 Android 平台选择边界均通过，未发生 11128。独立临时工作区，不包含用户项目；这不是手机实测。
- 手机设置分类使用 DSH Menu；原生控制器通过 DshUi 语义呈现为设置行、字段、说明与菜单，避免按钮平铺和重复返回。连接导入移入原 DSH Modal；设备状态订阅实时更新。保留文件动作与大文本编辑边界。
- 本地通过 20 项 SDK 流式、工具 Schema/返回、取消、超时、隐私、归档和 Android 平台启动回归、212 项设置消费、1219 项旧触屏布局检查、完整 JVM/脚本与 API 28/34 Java 编译；完整 APK 与新鲜运行包以本版 CI 日志为准。SDK 库由固定 lockfile 构建并随已签名 APK 分发，展开约 192 MiB，私有状态不允许分享。
- “检测连接”调用当前模型的官方 CLI 短请求，可能产生少量用量；目录刷新仍是来源明确的固定资料，不证明账号全部模型权限。详见 [CodeBuddy](CODEBUDDY.md)。

## 0.37.2 的原生动作可靠性

- 复现准备文件期间切换项目后仍打开旧分享的问题；文件请求绑定最初的 Activity 与工作区，真正打开前重新复核前台、窗口和项目。不匹配明确 CONTEXT_CHANGED，仅删除本次未交付的副本，保留原文件和既有分享缓存。
- 窗口处理器拒绝、UI 超时、调用取消和服务停止均取消并移除未开始的 FutureTask；已经中断的调用不再排队。截图在授权窗口创建期间取消也会撤销该请求，避免遗留等待者。
- ActivityNotFoundException / SecurityException 映射到无处理 App / 系统拒绝；缺失通知渠道明确报错，失败通知不消耗成功通知限流。文件暂存失败给出独立错误，不输出系统异常正文。
- JS 客户端保留 400 参数错误与 403 认证错误，区分真实响应期限与连接失败；有副作用的调用不自动重试。实际 ToolRuntime / Java HTTP / CLI 消费回归和不应答本机 peer 检查这些路径。
- 本轮新增 47 项实际 NativeBridge 可靠性边界检查，原 42 项动作/协调器和 59 项截图服务回归保留；真实内核工具链/HTTP/CLI/期限共 18 项通过。Android API 为替身，没有真机操作；完整 Android、真实内核与旧布局检查以本轮 CI/发布记录为准。

## 0.35.1 的语音错误 5 兼容修复

- 用户反馈小米 17 Ultra 在点击麦克风后立即出现错误 5。代码确认原版只检测是否注册服务，没有核对默认选择；默认识别器的错误 5 也没有回退系统窗口。设备的具体引擎/绑定原因仍需新诊断，不能仅凭错误码断言。
- 启动前核对实际默认组件、启用状态、端侧能力与系统窗口；默认缺失时直接使用可用系统窗口。端侧/默认识别器的兼容错误及启动异常按有界顺序回退，取消或后台状态禁止延迟打开窗口，不做重试循环。

- 诊断增加失败阶段、异常类和尝试路径，不记录音频或识别正文。设置页区分默认引擎与系统窗口；错误面板提供系统设置入口。
