# 正式版问题定位

<!-- dsh-doc-status:start -->
> 现行文档：按当前源码维护。 已发布 stable：**1.0.0**；源码：**1.1.0**；源码运行包：`payload-v14`；固定 DSH：`0.2.1-rc.3`（上游候选版）。[统一进度与验证边界](STATUS.md)。
<!-- dsh-doc-status:end -->

覆盖安装升级，保留原包名/签名。不要通过卸载、清空 `.dsh`、删除凭据或修改摘要来解决启动/更新问题。

| 现象 | 先看什么 | 可执行的下一步 |
|---|---|---|
| 小鲸鱼持续循环 | 启动阶段提示、运行日志及诊断中的 Startup milestones | 首次安装/分片更新可继续等待；失败页查看原因后重试。后台返回会重新核对握手，不强行露出未就绪网页 |
| 后台回来连接未恢复 | 任务中心连接状态、内核任务是否仍运行 | 保留当前页等待恢复；不要反复发送同一消息。任务未知时不自动刷新。必要时导出诊断再手动重连/重启 |
| 运行包清单不可信 | 最新 APK、下载源、大小/摘要错误 | 重试受校验的下载；旧环境可用时保留使用。中断标志/快照校验失败时保留现场，不删标志冒充成功 |
| 空间不足或解压失败 | 更新预检的剩余空间、快照和缓存占用 | 移走自己不需要的共享文件或清理系统缓存后重试。不要删除会话/凭据，也不要在内核运行时手动删 SDK |
| 配置恢复失败 | 口令、备份完整性、私有目录写入失败 | 原配置会尝试还原；中途退出由下次启动继续还原。保护记录损坏则停止写入并导出诊断，不清空配置 |
| 模型能列出但无法聊天 | 当前接入、模型、对话错误码 | 目录不代表权限。CodeBuddy 检测连接会发一个短请求，可能消耗额度；401 检查密钥/区域，403 检查模型权限，429 等待后再试，11128 检查账号渠道权限 |
| 上下文超限 | 错误提示、上下文占用 | 压缩当前会话或新建会话，保留旧历史。不要通过删除附件文件伪装压缩成功 |
| 缓存比例不符合预期 | 新旧会话累计范围、接入、服务商返回 | 0.40.2 起修正 CodeBuddy 重复计入缓存的问题；旧累计仍含旧口径。缓存读取、上下文占用和服务端实际命中是不同指标，不承诺固定比例 |
| 麦克风立即失败 | 前台/焦点、麦克风权限、Android 当前识别引擎 | 回到前台后重试；检查系统隐私开关和识别服务。系统窗口只在手动选择时打开，App 不在后台预热录音 |
| 外部编辑/分享无处理应用 | 文件类型、目标应用是否支持 content URI/编辑 | 换兼容应用；分享和普通打开只有读取权限。文本也可使用内置编辑器；外部应用保存结果需回到文件中核对 |
| 设置被挤压 | 字体缩放、方向、键盘是否展开 | 记录具体页面与操作，导出脱敏布局诊断。使用 App 内缩放选项；不要修改全局 CSS 或改小 480 视口 |

反馈时提供 App 版本、设备/Android 版本、发生时前后台状态、简短步骤和错误码。诊断 ZIP 通过“诊断与日志”手动导出；不用提交密钥、录音、会话正文或私人项目。

验收边界：自动回归、桌面浏览器触屏输入和 Android API 替身不等于手机实测。本轮不做真机/模拟器验证，小米 17 Ultra 的实际 ROM、麦克风、外部应用和耗电由用户安装验收。
