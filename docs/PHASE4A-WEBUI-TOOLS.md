## 归档状态与后续变更

本阶段对应实现已进入主分支。以下验收步骤、测试数量和发布限制保留当时版本语境；当前完成范围与未验证项目统一见 [STATUS](STATUS.md)。

## 原始阶段记录

阶段四 A 解决原生「工具」悬浮按钮覆盖 DSH 页面的问题。入口不再永久叠在
`WebView` 上，而是进入 DSH 自己的侧边栏底部；点击后仍打开现有原生「工具与设置」页。

本阶段不改变 `targetSdkVersion = 28`、包名、版本号、签名、工作区或升级路径，
也不直接合并 `main`、提升稳定版或发布新版。

## 已完成

- 删除右上角原生悬浮按钮及其语言刷新逻辑，DSH 页面不再被 App 控件覆盖。
- 以 DSH 的中英文「设置 / Settings」按钮为语义锚点，在同一侧边栏区域插入
  「App 工具 / App tools」。入口克隆当前 DSH 行、按钮、主题和动效类，参与正常布局；
  不依赖会随构建变化的 CSS 哈希类名。
- 侧边栏收起时隐藏克隆入口，只保留 DSH 自己的「设置」齿轮；展开后再显示带文字的
  「App 工具」，避免两个相同齿轮让用户误进原生设置。
- 点击入口通过既有、单向的 Web 控制台标记打开原生页面；没有增加
  `JavascriptInterface`，网页不能获得新的原生调用面。
- 每次真实页面加载都注入一次。脚本使用单例、DOM 标记、结构签名、
  `MutationObserver` 和低频恢复检查，应对刷新、SPA 路由重绘、侧边栏展开/收起、
  横竖屏、深浅主题、语言和字体变化；同一页面只保留一个入口。
- 注入失败时只给出一次非阻塞提示，绝不恢复遮挡页面的悬浮按钮。
  长按页面顶部 1.2 秒、通知栏「设置」和桌面快捷方式继续作为应急入口。
- 首次成功迁移时只显示一次提示，并持久记录；后续启动不重复打扰。

## 兼容与安全边界

- 当前定位依赖 DSH 设置按钮保留 `aria-haspopup="dialog"`，且可访问名称为
  `设置` 或 `Settings`。这比 CSS 类稳定，但上游若同时改变语义结构与名称，入口会缺失。
  此时 App 保持页面无遮挡，并提示使用应急入口。
- WebUI 入口是运行时 DOM 增强，不是 DSH 官方插件槽注册；上游 React 重绘可能短暂移除它，
  观察器会恢复。真机需要确认恢复过程无可见闪烁。
- 入口沿用 DSH 自身的主题、字号和 `prefers-reduced-motion` 行为；大字体下是否出现文本截断、
  折行或侧边栏拥挤仍需真实 WebView 验收。
- 测试 APK 只能证明构建、签名与静态回归通过，不能替代触摸、旋转、系统字体和后台恢复验收。

## 真机验收步骤

1. 在已安装的同签名版本上覆盖安装测试 APK；确认系统没有要求卸载，账号、会话、
   API 配置、默认工作区和命名项目均保留。
2. 打开任意对话和设置页，确认右上角不再出现 App 悬浮「工具」按钮，页面控件可完整点击。
3. 展开 DSH 左侧栏，在底部「设置」上方找到「App 工具」；点击后应打开原生
   「工具与设置」，返回后仍停留在原 DSH 页面。
4. 收起侧边栏，确认只显示 DSH 自己的「设置」齿轮，点击后打开 WebUI 设置；再次展开
   侧边栏后「App 工具」应恢复，TalkBack 焦点顺序应在 DSH 设置之前。
5. 刷新页面、创建新会话并在不同 DSH 面板间切换；每次只应出现一个 App 工具入口，
   不得重复、永久丢失或遮挡内容。
6. 连续横竖屏切换三次，再把系统字体调到最大；检查标签、点击区域、侧边栏滚动和
   原生工具页均无裁切。
7. 分别切换 DSH 深色/浅色主题和中文/英文；入口应继承主题，标签随当前 WebUI 语言变化。
8. 若系统开启“移除动画”或降低动画，确认入口没有额外强制动画或明显跳动。
9. 首次成功加载新版时应出现一次“入口已移至侧边栏底部”提示；强制停止再启动后不应重复。
10. 断网或在页面尚未完成加载时尝试入口；即使注入失败，也不得出现旧悬浮按钮。
    长按页面顶部 1.2 秒、通知栏「设置」和桌面快捷方式应仍可进入工具页。
11. 完成普通对话、工具调用、后台完成通知、文件分享、项目切换、插件授权、文件编辑和
    诊断导出各一次，确认阶段一至三功能没有回归。
12. 在“更新与维护”检查稳定/测试通道，但不要安装或发布新版本；确认当前验收包没有
    改写通道选择或触发数据迁移。

## 暂未完成

- 尚未用真实 Android WebView 验收不同厂商、系统字号、TalkBack 和旋转过程；这些结果必须由
  真机确认后再决定是否合并。
- 没有把入口做成 DSH 官方 `sidebar.footer.action` 插件。当前运行包没有向 Android 外壳开放
  安全的宿主注册接口，为此修改或分叉上游前端会扩大维护面，应单独评估。
- 没有提升稳定版或修改任何发布清单；测试通过后仍需人工决定合并与后续版本策略。
