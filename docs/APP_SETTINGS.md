0.40.0 移除头像上方的独立 App 工具按钮，只保留内核自有设置/账号入口；旧标记节点会清理，不再克隆按钮或安装长期 DOM 观察器。设备摘要并入通用页，不增加单独“设备”分类；模型扩展使用原风格的展开行，嵌套确认显示自己的标题。设备控件按原字体/行高、主题与分组排列。

状态刷新与用户操作分开：每 1.5 秒读取一次空闲页面，输入、隐藏或真实操作期间暂停轮询。刷新期间的点击会等待该次读取后执行，不能因后台锁而悄悄丢弃；关闭页面后尚未发出的操作取消，不覆盖用户编辑。

0.39.0 将手机分类切换改成原 DSH Menu；DshUi 的标题、区块、字段和提示带有语义，网页按原设置行组织，互斥选项复用 Menu。导入连接使用原 Modal；嵌套弹层、返回、长字段和文件操作保留原生命周期。实际测量涵盖最窄 480 CSS px 视口、长标签与多选项，不用缩小全局视口掩盖挤压。

0.38.0 将设备功能直接放进 DSH 原有设置结构。通用页包含文字缩放，模型页包含 CodeBuddy 导入、项目默认与目录维护，会话、任务、文件、数据、维护和诊断使用同一个导航。旧控制器保留实际行为，由 `WebSettingsHost` 呈现为 DSH 的 Button、Input、Modal 和主题令牌。内核未就绪时仍可使用维护回退入口。

## 可用流程

| 页面 | 操作与结果 |
|---|---|
| 会话管理 | 真实列表、标题筛选、20 条分页、重命名、归档、恢复、恢复并继续、新建对话 |
| 回收站 | 删除隐藏会话、恢复及继续；保留核心记录，不释放存储空间 |
| 模型 | 打开服务商、默认/项目模型与更新模型列表；账号快捷键打开原账号余额页 |
| 通用 | 原 DSH 主题/语言设置与文字缩放 |
| 文件 | 预览、文本编辑、新建、其他应用打开/编辑、系统分享及多选/回收站 |
| 任务 | 实际状态、连接恢复与时间线 |
| 更新 | App 更新、运行包恢复、明确的重启应用配置入口；中断任务须确认 |
| 数据 | 项目、文件、加密配置备份、插件；关闭子工具返回数据页 |
| 诊断 | 日志、脱敏 ZIP、网络检查；网络检查返回诊断页 |

会话操作通过当前同源 Cookie 认证的真实 RPC 执行。成功重新读取列表，失败显示可重试错误；15 秒超时提示刷新确认结果，避免把超时当作未发生。轮询不打断慢请求，不覆盖操作错误，关闭页面后不回写。运行或排队工作由核心 registry 拒绝归档/删除。

## 实现边界

`AppSettingsUi.java` 严格、幂等地适配固定 payload-v13 的 General 客户端、SessionController 和会话客户端缓存，兼容旧运行包。锚点不符时不静默通过启动，不使用 DOM 文案找按钮。

`session-tools-core.js` 注册受原认证保护的 `session/androidList`、`androidTrash`、`androidRestore`，调用原列表与 archive/unarchive。App 不改写核心会话日志、不删除工作区。回收站只保存 ID 和时间到 `.dsh/.native-session-trash.json`，0600、限大小、排他临时文件、文件同步和原子替换；发布失败回滚归档。缓存/队列按解析后的 DSH_HOME 共享，避免每个 Remote 请求的代理身份不同而丢失并发修改。损坏 journal 报错，不当作空回收站。原列表和已启用的正文搜索过滤回收站，新增/提示/分叉/改名/模型/队列操作拒绝已删除会话。子 agent 不作为普通对话列出。正文搜索是上游 opt-in，默认关闭；本版不擅自开启，标题筛选始终可用。

恢复通过原 added 事件清除客户端缓存 removed 标记，再使用原 `uiWorkspace.openSession`；真实 composer 可继续发送并显示回复。新建使用原 `startSession`，不仿造编辑器。

设备呈现协议只接收固定页面、当前控件 ID、分块输入/读取、返回和关闭操作；文件入口另接受固定 browse/edit/open/share 与受可写根约束的路径。每页使用随机 session，验证字段、大小、前台与准确本机来源。旧控件、后台请求、只读字段和读取已有密码均被拒绝；关闭时执行控制器清理。硬件返回先交给当前设置/确认层，未处理才显示退出提示。保留 480 窄屏视口。

文件预览、交付卡和文件树直接注册文件动作 slot；固定预览头增加稳定属性锚点，动作占独立行，避免 38px 头部把换行按钮压入正文。详见[文件操作](FILE_ACTIONS.md)。私人连接与目录来源见[CodeBuddy](CODEBUDDY.md)。

配置恢复先停止并等待旧托管进程退出，再持有静态 `runtimeConfigLock` 写入，避免 Activity 重建的启动读取半写配置；停止失败不覆盖。恢复完成自动重启，插件页有应用并重启按钮，安装进行时不能应用。设备工具保留返回父页回调。
