0.33.12 的 App 设置使用 DSH 自带的设置弹窗和 `settings.section`，深浅主题、语言、导航与原按钮/输入/确认框统一。侧栏 App 工具、长按顶部及系统快捷方式打开同一入口；内核尚未就绪时保留启动维护入口。

## 可用流程

| 页面 | 操作与结果 |
|---|---|
| 会话管理 | 真实列表、标题筛选、20 条分页、重命名、归档、恢复、恢复并继续、新建对话 |
| 回收站 | 删除隐藏会话、恢复及继续；保留核心记录，不释放存储空间 |
| 模型 | 打开服务商、默认/项目模型与更新模型列表；账号快捷键打开原账号余额页 |
| 显示 | 原 DSH 主题/语言设置与 App 文字缩放 |
| 任务 | 实际状态、连接恢复与时间线 |
| 更新 | App 更新、运行包恢复、明确的重启应用配置入口；中断任务须确认 |
| 数据 | 项目、文件、加密配置备份、插件；关闭子工具返回数据页 |
| 诊断 | 日志、脱敏 ZIP、网络检查；网络检查返回诊断页 |

会话操作通过当前同源 Cookie 认证的真实 RPC 执行。成功重新读取列表，失败显示可重试错误；15 秒超时提示刷新确认结果，避免把超时当作未发生。轮询不打断慢请求，不覆盖操作错误，关闭页面后不回写。运行或排队工作由核心 registry 拒绝归档/删除。

## 实现边界

`AppSettingsUi.java` 严格、幂等地适配固定 payload-v12 的 General 客户端、SessionController 和会话客户端缓存。锚点不符时不静默通过启动，不使用 DOM 文案找按钮。

`session-tools-core.js` 注册受原认证保护的 `session/androidList`、`androidTrash`、`androidRestore`，调用原列表与 archive/unarchive。App 不改写核心会话日志、不删除工作区。回收站只保存 ID 和时间到 `.dsh/.native-session-trash.json`，0600、限大小、排他临时文件、文件同步和原子替换；发布失败回滚归档。缓存/队列按解析后的 DSH_HOME 共享，避免每个 Remote 请求的代理身份不同而丢失并发修改。损坏 journal 报错，不当作空回收站。原列表和已启用的正文搜索过滤回收站，新增/提示/分叉/改名/模型/队列操作拒绝已删除会话。子 agent 不作为普通对话列出。正文搜索是上游 opt-in，默认关闭；本版不擅自开启，标题筛选始终可用。

恢复通过原 added 事件清除客户端缓存 removed 标记，再使用原 `uiWorkspace.openSession`；真实 composer 可继续发送并显示回复。新建使用原 `startSession`，不仿造编辑器。

原生桥仅允许六种设备工具导航命令，检查字段、大小、ID、语言以及当前页和 console 来源的准确 loopback host/port；没有任意脚本、路径或 RPC。前端收到确认才关闭设置，超时/拒绝可重试。原生工具颜色使用当前 DSH 令牌，不添加全局 CSS 或改变 480 窄屏视口。

配置恢复先停止并等待旧托管进程退出，再持有静态 `runtimeConfigLock` 写入，避免 Activity 重建的启动读取半写配置；停止失败不覆盖。恢复完成自动重启，插件页有应用并重启按钮，安装进行时不能应用。设备工具保留返回父页回调。

## 验证与交付

`app-settings-consumer.mjs` 消费生产 Java 生成的补丁和真实内核，以独立临时数据验证归档、回收站、恢复继续、真实 composer 合成回复、并发 journal、磁盘发布失败回滚、重启后恢复、读取失败/重试、六种原生命令和原 General/Account 导航。六组 320/360/436/600/869 触屏、横屏、中英文、深浅主题检查真实控件边界。

本轮已通过 385 项设置消费检查与 85 项账号回归；没有付费提示词或用户凭据。正式计数以 [STATUS](STATUS.md) 本次记录为准。手机 WebView、系统浏览器、硬件返回、大字体及不同 ROM 仍需真机反馈。
